古曰「知知夫國」、「无邪志國」。
崇神帝置知知夫國，以知知夫彥命爲造；成務帝定无邪志國，兄多毛比命爲造《舊事本紀》。邪又作"射"。按本書別載胸刺國，无邪志卽胸刺也，故不取。安閒帝時，置橫渟、橘花、多冰、倉樔屯倉《日本書紀》。大化改制，定爲武藏。建秩父、橫見、橘樹、多磨、久良諸郡《日本書紀》、《和名鈔大意》。按武藏始見《景行紀》，蓋追書也。名義未詳。《續日本紀》云：「國號武藏，旣呈戢武崇文之祥。」是本頌辭，故云爾，非本義也。屬東山道。靈龜二年，置高麗郡。天平寶字二年，建新羅郡按《延喜式》、《和名鈔》作新座郡，後改名也。寶龜二年，改屬東海道《續日本紀》。管郡二十一，鄕一百十九。國府在多磨郡。距京師行程上二十九日，下十五日《延喜式》、《和名鈔》。東至下總及海，南至甲斐、相模，西至上野、信濃，北至上野、下總《武藏國圖》。原野曠漠，民烟稀疏，盜賊横行，稱爲難治《續日本後紀》、《新古今和歌集》、《續後撰和歌集》、《新編武藏風土記大意》。

多磨川，自甲斐來，貫多磨、橘樹、荏原三郡注海。
荒川發于秩父郡，過榛澤、男衾、大里、埼玉、足立、豐島諸郡，爲墨田川歸海。
利根川自上野來，經賀美、兒玉、榛澤、幡羅、埼玉諸郡，以界上野，東入下總《新編風土記》、《國圖》。

及王綱漸弛，皇胄之沈滯下僚者，憤相門專橫，去赴遐陬，私占田宅，封殖宗黨，武斷鄕曲《扶桑略記》、《今昔物語》、《堪囊鈔》。所謂家子郎黨，遍滿郡國，一朝有事，率以臨軍，自稱旗頭黨長《保元物語》、《平治物語》、《陸奥話記》、《源平盛衰記》、《熊谷家譜》。如本國七黨，裂土分民，互相雄視，畠山、熊谷、平山諸族，隸屬源家，爭爲之用《東鑑》、《武藏七黨系圖》。源賴朝収攬，遂成其業，以本國直隸鎌倉，以終北條氏之世《東鑑》、《保曆間記大意》。足利尊氏倣其故智，置族基氏管焉，新田氏屢相爭之，而不能得志矣《太平記》。

## 久良郡
本書訓久良岐，或作海月，訓通。中《令義解》、《和名鈔》

【中】《令義解》、《和名鈔》

安閒帝時，國造笠原直使主，獻倉樔屯倉，蓋此《日本書紀》。後建爲郡《和名鈔》。

東臨海，南鄰相模御浦郡，西接都筑郡，及相模鎌倉郡，北沿海接橘樹郡《國圖》。領鄕八《和名鈔》。

# 鮐浦按諸本作鮎浦，訓「布久良」，鮐、鮎以字體相似誤。今社家、分寺、分諸村，稱六浦鄉，在郡南，蓋古鄉地。。後曰「六浦鄕」。《鎌倉黄梅院文書》。或作六連。又六浦莊。《本郡稱名寺文書》。建久中，梟上總忠光于此。仁治建長間，開大路以通鎌倉《東鑑》。當時隸鎌倉郡。有金澤地，北條實時居此，稱金澤氏《金澤系圖》。有稱名寺，文永中，其裔顯時所建。龜山帝詔爲敕願寺《本寺緣起及文書》。寺置黌舍，藏内外羣籍，稱曰金澤文庫《義堂日工集》、《慕京集》、《鎌倉大草子》。卽顯時所建。有金澤港今洲埼村，爲鎌倉三港之一《回國雜紀》，蕃舶屢來泊《名所和歌物語》。元弘中，有富田鄉亙宿、赤井、坂本三村，後曰蒲里谷鄕《稱名寺文書》。有冰取澤今冰取澤村。建曆中，源實朝率文人來賞秋花。《東鑑》。
# 大井今不詳。按今井户谷村，在大田西，井户與堰埭訓近，疑其遺名。康曆中，大井氏居此。《鎌倉圓覺寺文書》。有弘明寺，有鎌倉定爲祈願所《東鑑》。在弘明寺村
# 服田今不詳。按有太田村。服、太訓相近，姑附備考。有蒔田鄉今蒔田村。吉良成高居此，稱蒔田氏《蒔田系圖》、《新編風土記》。
# 星川今下星川村，入橘樹郡。上星川村入都筑郡，接本郡西北，蓋星川朝臣所居。《姓氏錄》。按星川氏與石川朝臣同祖，郡有石川鄕，亦有由矣。有神柰川鄕《鶴岡八幡宮文永三年文書》。今神柰川驛。有青木壘在青木村。足利尊氏爲新田義興所攻，逃入狩野川城，卽此。《園太曆》。狩野川、神柰川，同訓。正中中，有芝宇宿《遊行歷代記》。今芝生村，入橘樹郡。
# 郡家《武藏志料》云：「宫下村，蓋郡家之轉。」今按笹下鄉有栗木村，與久良聲相近，或其地也。附存備考。
# 諸岡今諸岡村，入橘樹郡。後曰師岡保《鶴岡八幡宮文書》、《京都本法寺過去帳》。延久中，有鶴見鄕《鶴岡八幡宮文書》。有秋田義景別業，將軍藤原賴經臨焉《東鑑》。元弘建武際，官軍與賊屢戰于此《梅松論》、《千葉系圖》、《佐竹家譜》。
# 洲名今不詳。按郡東北有本鄉村，屬本牧領，蓋此。應永中，有平子鄕、禪馬鄕竝鄕名存，石川鄕《石川寶生寺文書》。今石川村。有秀閒港，又曰「橫濱」《新編風土記》，今橫濱村。
# 良椅今不詳。按金澤領吉原村有大橋地，疑其遺名。有東漸寺在杉田村。正安中，北條定長建，所謂關東十刹之一也。《本寺傳記》、《新編風土記》。

## 多磨郡
磨，一作麻。

【中】《令義解》、《和名鈔》

有多麻河《萬葉集》。因名。古有多冰屯倉《日本書紀》。按氷恐末字譌。

東連橘樹、荏原、豐島三郡，南界都筑郡，及相模高座郡，西抵甲斐都畱郡，北接秩父、高麗、入閒、新座四郡《國圖》。按鎌倉時，分曰多東、多西，見《新編風土記》引古文書。入閒、埼玉，亦分爲東西二郡，蓋當時私制也。故今不書。領鄕十《和名鈔》。

# 小川（今小川村，在郡中央）。應永中，鄉名尚存。《二宮祠寫經跋》。有小川牧，《延喜式》。小河祠《應永十九年文書》。在二宫村。有阿伎畱社《延喜式》。阿岐畱川《國圖》。有御岳山《國圖》。一名秩父山，接甲斐。傳言：日本武尊東征，駐軍于此《御岳權現社記》。
# 川口（今川口村，在小川西南）。元應中，鄕名尚存。《本村烏栖寺鐘銘》。當時分爲南北二鄕。有小佛嶺《武藏演露》。屬駒木野村，以界武相。多磨横山《萬葉集》。今横山村。山脈延亙橘樹郡界。有橫山莊《東鑑》。屬村四十四。小野義隆爲國守，食邑於此，宗族蕃衍，號曰橫山黨。《七黨系圖》。源賴朝之興，舉族應之。後黨和田氏，收其邑，授大江廣元《東鑑》。有由比牧《延喜式》。今二分方村有由井野。日野宗忠弟宗弘，稱「由比牧別當」。有日野地今日野本鄉村。日奉宗忠居此，稱日野氏，是西黨祖也《七黨系圖》。有日奉祠《新編風土記》。在平山村。傳言：平山季重居此。有小澤鄕，稻毛重成子重政領之，稱小澤氏《東鑑》。有金井原（今金井村）。正平中，新田義宗與足利尊氏戰于此。《觀應三年古文書》。有高坂鄕（今高坂村）。應永中，足利義滿施京師鹿王院《應永、永享古文書》。
# 小楊（今青柳村，在小川南，其地沿多磨川，屢被水患，民居變易，古域不可考）。
# 小野（今本宿村有小野社，卽其遺名。在小楊北）。有小野社《延喜式》。古國府在此《和名鈔》。今府中驛有六所宮，世稱總社《新編風土記》。鎌倉特崇敬之《東鑑》。有分陪河原今作分梅。元弘三年，新田義貞擊鎌倉兵于此。《太平記》。有國分寺《延喜式》。在國分寺村。承和中，男衾郡大領壬生福正造七層浮屠《續日本後紀》。有立川鄉《柴埼八幡祠銅佛識》、《四神地名錄》。今立川村。西黨有立川氏，居此。《七黨系圖》。有山口莊元弘三年，新田氏攻北條泰家于此《梅松論》。有村山地。村山貫主平賴任所居，是爲村山黨祖《七黨系圖》。治承中，其裔賴直屬源賴朝《東鑑》。有阿豆佐美社《延喜式》。有久米川今久米川村。元弘三年，新田義貞破鎌倉兵于此《太平記》。有狹山《千載和歌集》、狹山池《夫木集》、《歌枕名寄》（一名筥池）。有武藏野，曠漠無際《新古今和歌集》、《續後撰和歌集大意》。按其野西連秩父，東亙高麗、入閒、新座諸郡云。天長末，國介當宗宿禰家主等，置悲田所于多磨、入閒二郡界，以救飢病者《續日本後紀》。今有南北秋津村，分屬二郡，蓋其地也。
# 新田今有布田宿，亙石原國領諸驛，曰「布田五宿」。在小野東）。有布多天神社《延喜式》。
# 小島今不詳。《新編風土記》以布田屬邑小島分擬之，然其地屬布田，恐非古鄕。附竢後考。
# 海田今鎌田村，在郡東，或此。
# 石津今不詳。
# 狛江今稱佐須、深大寺二村，曰狛江鄕，在新田北。一說鎌田村有駒井村，是狛江也，今不取。承和中，本鄕節婦刑部直眞刀自咩，賜位二階《續日本後紀》。本書狛誤作猪。有虎狛社《延喜式》。西黨有狛江氏《七黨系圖》。承元中，狛江增西居此《東鑑》。按二書狛作柏或泊，恐誤。有飛田給地今飛田給村，蓋悲田所料也《新編風土記》。
# 勢多今荏原郡有瀨田、世田谷二村，卽是。後曰世田谷鄕《吉良家譜》。

## 橘樹郡

安閒帝時，國造笠原直使主，獻橘花屯倉，卽此《日本書紀》。後建爲郡《延喜式》、《萬葉集》。
