大（《延喜式》）。古稱大倭（《日本書紀》、《續日本紀》。按《萬葉集》作倭，又山常、山跡）。或作日本，又大養德（《續日本紀》、《萬葉集》）。讀“云耶麻騰”，言山内也，蓋取青山四周之義（《古事記》、《日本書紀大意》。按歷朝都此，故加大字）。

太祖之定中州，首定倭、葛城。國造猛田、磯城縣主。綏靖帝置春日縣主。孝安帝置十市縣主，尋建鬬鷄國及高市、山邊、層富三縣（按加葛城、磯城、十市，稱曰六縣）。有雲梯、三宅、那羅、勾、室、片鹽、讚岐、池上、飽波、忍海、内、吉野、菟田、山村、大宅、額田、高宮、大坂、當麻、大市、三輪、泊瀨、忍坂、黑田、星川、石上、磐余、檜隈、來目諸邑（《日本書紀》、《古事記》、《姓氏錄》、《延喜式》、《萬葉集》）。後立爲郡、爲鄕（《延喜式》、《和名鈔》）。

天平九年，改大倭曰大養德；十九年，復舊（《續日本紀》）。天平勝寶元年，定爲今字（《神代卷口訣》、《拾芥鈔》、《伊呂波字類鈔》）。管郡十五，鄕八十九。國府在高市郡（《延喜式》、《和名鈔》）。距京師行程一日（《延喜式》）。東至伊勢、伊賀，南連紀伊，西接河内，北界山城。山嶽連亙，庶物繁阜，南北長，東西短。吉野一郡，殆居其半。葛城山界河内，吉野山羣峯秀峙，連紀伊，三國嶽跨伊勢、紀伊。大和川西入河内，吉野、丹生、十津諸水南赴紀伊（《大和志》、《大和國圖》）。

初，伊弉諾尊稱此國曰“日本浦安國”，又曰“細戈千足國”、“磯輪上秀眞國”。大已貴命謂“玉牆内國”。饒速日命稱“虚空見日本國”。太祖嘗曰：“美哉國也，猶蜻蛉之呫臀矣。”因有秋津洲之號。是實天祖垂統之地，明德馭㝢，照臨六合。後命天孫西幸日向，所謂天降者，蓋謂之也。

迨太祖時，戡定東方，奠都本國。列聖繼紹，雖世異其邑，未敢遷他國者，以祖宗基業之邦也（《日本書紀》、《古事記》、《延喜式大意》）。天武帝已遜于吉野，決意而東，大敗東兵于近江，遂登大位，都于飛鳥（《日本書紀》）。和銅以後，定都平城者凡七世，皆遵祖業也。延曆中，遷都山城（《日本紀略》），號平城曰“南都”，尚列四畿之上（《江家次第》、《源平盛衰記》、《平家物語》、《大和志》）。平城帝搆難，謀復故都，嵯峨帝遣兵邀之，事平（《日本紀略》）。元弘中，後醍醐帝在隱岐，護良親王據吉野城，與楠正成等相應，以斃大憝。延元初，帝南狩，居吉野行宮，而謀克復。賊屢來犯，終不得其志者，以内據險阻，外控河攝也。及後龜山帝還幸京師（《神皇正統記》、《太平記》、《續神皇正統記》）。

## 添上郡
中（《令義解》、《和名鈔》）。初曰“層富縣”（《日本書紀》一作“曾布”），後爲二郡，改今字（《日本書紀》、《延喜式》。按《欽明紀》有添上郡，蓋追書也）。東南至山邊郡，西接添下郡，北界山城相樂郡（《大和志》、《國圖》）。領鄕八（《和名鈔》）。

# 山村（按《日本靈異記》有山村中里，今中莊村，蓋是）。欽明帝置百濟人已知部于此（《日本書紀》），其族以山村氏焉（《姓氏錄》）。元正帝嘗幸此（《萬葉集》），後曰“山村里”（《今昔物語》）、“山村莊”（《東大寺要錄》）。有藤原里（《夫木集》，今藤原村）、藤原川（《大和志》）。永井池（《堀河後百首》，今永井村）。
# 楢中（今楢村，在山村西南）。古稱和珥（《日本書紀》、《延喜式》、《大和志》）。雄略帝時春日和珥氏居此（《日本書紀》）。後有和邇、櫟本、白地、橫田諸莊（《東大寺要錄》，今竝存村名）。有和珥社（《延喜式》），有和珥坂（屬櫟本村）。太祖誅居勢祝於此，大彥命討武埴安彥，鎭忌瓮於和珥武鐰坂，亦此（《日本書紀》、《古事記》。按《古事記》有金鉏岡、金鉏，今無所考，蓋與武鐰同地）。有和珥池（屬池田村），仁德、推古二朝所修（《日本書紀》）。有三椅（今上下三橋村）。元明朝遣騎兵迎新羅使于此（《續日本紀》）。有辰市（今稱東西九條等四村，曰辰市莊）。有沽閒泉（《散木集》，在東九條村）。有柿本寺（屬櫟本村），柿本人麻呂墓在焉（《清輔家集》、《人麻呂勘文》）。
# 山邊（今佐保、法華寺諸村，在郡西北，卽是）。有藏寶山（又作佐保，在法蓮村北），佐保川（《萬葉集》）。有雍良岑（《續日本紀》、《大和志》，又作欲良，在法華寺村），卽“宇柰太理地”，高御魂社在焉。有柰保及佐保山陵（《延喜式》）。有法華寺，孝謙帝禪位後御于此（《續日本紀》）。有海龍王寺（《大和志》，竝在法華寺村，《續日本紀》稱隅寺）。有宜寸川（《萬葉集》，一名水屋川），薦枕川（《大和志》，一名薦川）。有高橋社（《延喜式》），崇神帝時大神掌酒活日居高橋邑，卽此（《日本書紀》）。有田村宮（《續日本紀》，在薦川東），田村里（《萬葉集》），有藤原仲麻呂田村第，孝謙帝幸焉（《續日本紀》）。吉田連貫此（《姓氏錄》）。有棃原莊（《東大寺文書》、《南都古京圖》），天平勝寶中迎八幡神，造新殿於宮南棃原，蓋此（《續日本紀》。按《江家次第》：棃子原，在南都二條大路南）。
# 楊生（今有大小柳生、北柳生三村，在郡東北），後曰楊生莊（《法隆寺別當次第》、《太子傳玉林鈔》）、小柳生莊（《西大寺田畠目錄》）。有夜支布山口社（《延喜式》）。有深江川（《大和志》）。
# 八島（今郡西南有八島鄕，屬邑十八），有崇道天皇八島陵（在山村）。有八島寺（《延喜式》，《元亨釋書》作山階，在八島村）。有清隅池（《萬葉集》、《堀河後百首》，在高樋村），後曰清澄莊（《東大寺要錄》）。出雲母（《大和志》。按《續日本紀》、和銅六年，大和國貢雲母，疑此）。有田原東陵、西陵（《延喜式》）。
# 大岡（今廣岡村，在楊生西北，卽是），蓋大崗忌寸所居（《姓氏錄》）。初葬光仁帝於廣岡陵（《續日本紀》），卽此（《大和志》）。
# 春日（今南都之地），古曰春日縣（《日本書紀》）。仁德帝時彥國押人命裔仲臣居此，稱春日氏（《姓氏錄》。本書云：仲臣家富，委糟爲堵，因稱糟垣氏，後更春日字，似地名始此者。然綏靖朝已有春日縣，則仲臣因地命氏也）。後曰春日莊（《東大寺要錄》）。有春日山，一名三笠山（《萬葉集》），春日社在此（《延喜式》）。有借高野（《萬葉集》，今鹿野苑村）。春日野（《萬葉集》、《古今和歌集》）。烽火山（《大和志》，在鹿野苑東），和銅中置烽以通平城。有飯盛山（在若草山北），寶龜中採西大寺塔礎于此（《續日本紀》）。有那羅山（在柰良坂村），崇神帝時大彥命陣於此，大兵蹢跙草木，因名（按本注：蹢跙，此云布瀰那羅須，那羅須，令平也，故亦作平山。後稱南都曰平城，本于此。或作柰良，又寧樂、乃樂、諾樂，竝音通。又按《古事記》，古自山城入本國必由此，故稱曰那良戶云）。壬申之亂，將軍大野君果安破大伴連吹負于此（《日本書紀》）。有平城坂上陵（《延喜式》）。有般若寺（在柰良坂村），元弘之變，護良親王避難之處（《太平記》）。春日山西，卽平城京（《續日本紀》、《萬葉集》、《國圖》。今左京曰南都，右京曰西京）。有平城園（《延喜式》）。有東大寺（《續日本紀》）。有興福寺（《三代實録》、《興福寺縁起》）。有元興寺，所謂平城飛鳥地（《萬葉集》）。有朝野宿禰魚養墓（《大和志》）。有紀寺（《續日本紀》、《國圖》，一名璉城寺）。有狹井川邑（《大倭社注進狀》，又名春日率川邑），有率川社（《延喜式》）、春日率川宮（《日本書紀》）。有春日率川坂上陵。有率川莊（《延喜式》）。有猨澤池（《大和物語》、《夫木集》）。
# 大宅（按大宅見《武烈紀》，《物部影媛歌》。今白毫寺村有宅，春日地，卽名之遺）。聖武帝時大宅氏居此（《東大寺奴婢籍帳》），後曰大宅莊（《東大寺要錄》）。有大宅寺，相傳難波皇子所立（《大和志》，址在白毫寺西）。有高圓山、高圓野，有高圓離宮（《萬葉集》），和銅元年幸春日離宮，卽此（《續日本紀》）。有吉備眞備墓（《大和志》，在高畠村）。有新藥師寺（《續日本紀》、《國圖》）。

## 添下郡
下（《令義解》、《和名鈔》）。東接添上郡，西南至平羣郡，北界山城相樂郡（《大和志》、《國圖》）。領鄕四（《和名鈔》）。

# 村國（今不詳）。有阿部命婦村國墓（《延喜式》）。
# 佐紀（又作佐貴，今超昇寺、常福、有狹城池、垂仁寺諸村在郡東北，卽其地），帝所開。又曰盾列池（《日本書紀》、《續日本紀》。盾列一作楯波，又盾波），在常福寺村，稱西池。有狹城盾列池上、池後二陵（《延喜式》），故曰山陵莊（《西大寺田畠目錄》，今山陵村）。有楊梅宫，寶龜四年所置（《讀日本紀》，址存常福寺村）。有楊梅陵（《延喜式》，在盾列池北），古屬添上郡。有高野陵（《續日本紀》、《延喜式》）。高野原。有佐紀山、咲野，有佐紀宫（《萬葉集》，今超昇寺村有内裏地，蓋是）。佐紀社（《延喜式》）。秋篠鄉（《西大寺田畠目錄》，今秋條村）。按《西大寺所藏班田圖》，京北二條五里曰秋篠里，有秋篠寺；其一條三里曰前道里，卽佐紀道也。有秋篠寺（《元亨釋書》、《南都古京圖》）。秋篠山（《夫木集》）、秋篠川（《大和志》）。菅原鄉（《法隆寺資財帳》、《萬葉集》，今菅原村），後曰菅原莊（《西大寺田昌目錄》）。有伏見鄕（《元亨釋書》、《古今和歌集》），有菅原伏見東陵、西陵。有菅原社（《延喜式》）、菅原寺（《元亨釋書》）。土師氏居此，後改賜菅原、秋篠二氏（《續日本紀》、《姓氏錄》）。有西大寺（在西大寺村）。招提寺（《續日本紀》、《大和志》，在菅原南五條村）。有赤膚山（《新續古今和歌集》、《大和志》，在招提寺西）。勝閒田池（《萬葉集》、《大和志》）。有藥師寺（在砂村天平勝寶元年，在六條村），年爲行在所（《續日本紀》）。
# 矢田（一作箭田），今有矢田村，在郡西。矢田部氏所居（《姓氏錄》）。建武中曰矢田莊（《吉水院文書》）。有矢田社（《延喜式》）、矢田野（《古事記》、《大和志》）、矢田山（按《行基年譜》有矢田岡本村）。山出雲母（《大和志》）。有矢田池，養老七年開（《續日本紀》）。迹見池（在池内村），垂仁帝三十五年開（《日本書紀》）。有新城宮，寶龜五年幸此（《續日本紀》、《國圖》，址存新木村，在迹見池東北）。太祖誅新城戶畔於波哆丘岬，天武帝遣人新城察其形勢，皆此（《日本書紀》）。有藥園宮（今郡山有藥園八幡宫），天平勝寶元年大嘗於此（《續日本紀》）。羅城門墟在焉（《續日本紀》、《大和志》，礎石尚存）。
# 鳥貝（按《續日本紀》、《延喜式》作鳥見，《和名鈔》本注止利加比，說者云。《萬葉集》有取替川，與鳥貝訓通，川今尚存。或鄕曰鳥見，川曰鳥貝，後遂混和）。和銅中，郡人倭忌寸果安以孝友聞，感化登美、箭田二鄕是也（《續日本紀》）。有登彌社（《延喜式》）、登美寺（《續日本紀》，址在木島村），後曰鳥見莊（《西大寺田畠目錄》，今屬邑三）。有添御縣社（《延喜式》）。有龍王峯（在高山村北），鳥貝川出（《大和志》。《萬葉集》作取替，一名鳥見小川）。

## 平羣郡
下（《令義解》、《和名鈔》）。初稱飽波郡（《日本書紀》），後更今名（《延喜式》）。東鄰添上、山邊二郡，南接城下、廣瀨、葛下三郡，西界河内、河内高安、大縣三郡，北抵河内讚良郡（《大和志》、《國圖》）。領鄕六（《和名鈔》）。

# 那珂（今不詳）。
# 飽波（今郡南東安堵村有飽波地，《西大寺田畠目錄》作惡波）。敏達帝時虹見飽波村（《太子傳補闕記》）。有飽浪宮，神護景雲中所幸（《續日本紀》，村址存安堵）。有飽浪葦牆宮，廏戶皇子居焉（《大安寺伽藍緣起》）。後曰安堵莊（《東寺文書》），蓋吾礪廣津邑也（《日本書紀》），卽廣來津公所居（《姓氏錄》）。

## 葛上郡
中（《令義解》、《和名鈔》）。初曰高尾張邑，有土蜘蛛據此，太祖東征，掩葛網殺之，因更號葛城國（城又作木），以劍根命爲造（《日本書紀》）。後降爲二郡，曰葛上、葛下（《日本書紀》、《續日本紀》、《延喜式》）。東至高市郡，南接宇智郡，西界河内石川郡，北鄰忍海郡（《大和志》、《國圖》）。領鄕十（《和名鈔》）。

# 日置（今郡北俱尸羅村有日置地），蓋日置造、日置倉人所居（《姓氏錄》）。
# 高宮（今宫戶、森脇諸村，在日置南，卽其地）。應神帝時置漢人于高宮邑，卽此（《日本書紀》）。仁德磐之媛皇后桑梓之地（《日本書紀》、《古事記》）。皇極帝時，蘇我蝦夷立祖廟于此，有高丘宫（《日本書紀》）。

# 巨勢（有巨勢山口社（《延喜式》）。有巨勢寺（《日本書紀》，址在古瀨村），後曰部坂莊、戶毛莊（《東寺文晝》、《吉水院文書》，今有重坂、戶毛二村）。有重坂山、戶毛川出（《大和志》）。
# 桑原（今不詳）。應神帝時置漢人于桑原邑，卽此（《日本書紀》）。後桑原直、桑原村主居焉（《日本書紀》、《續日本紀》、《姓氏錄》）。

# 大坂（今郡西増村有大坂地）。崇神帝時埴安彥反，其妻吾田媛引軍從大坂進，五十狹芹彥命擊破之。倭迹迹媛命薨，採石於大坂山築墓，亦此（《日本書紀》）。古往河内必由此，故稱曰大坂戶（《日本書紀》、《古事記》、《萬葉集》）。壬申之亂，大伴吹負屯于此，防河内軍。天武帝七年，始置大坂山關（刻本坂作江，誤，今從一本）。有關屋村，蓋其遺名。葛城山，雄略帝嘗獵于此（《日本書紀》，亙忍海、葛下二郡，西跨河内）。葛城川出巓，曰高天山（一名金剛山）。有高天寺（一名金剛山寺）。有朝原寺、有石寺（《大和志》、《國圖》）。太古天降命，降葛城豬石岡，卽此（《姓氏錄》）。有臍見長柄丘（《日本書紀》）。有長柄社（《延喜式》），長柄首居焉（《姓氏錄》）。有名柄池（《夫木集》，在名柄）。長柄杜，天武帝觀馬於此（《日本書紀》）。有朝妻山（《萬葉集》，妻一作孺，又津閒）。今朝妻村，在名柄東南，避箇小坂屬之（《日本書紀》）。應神帝時置歸化秦民於朝津閒，掖上地，朝妻造亦出此（《姓氏錄》）。有掖上池（在井户村），推古帝所開（《日本書紀》）。有葛城寺（址存朝妻村），光仁帝之在藩邸，童謠所謂葛城寺是也。有菩提院（《續日本紀》，在伏楢原）。今稱楢原谷，屬村七。有茂岡（《萬葉集》）。
# 神户（今呼水原村），葛木犬養社在焉（《延喜式》）。野佐味等六村曰佐味莊，在大坂南，卽古鄕地。有高鴨社（《延喜式》），蓋其神邑也。古稱佐糜邑，應神帝時置漢人於此（《日本書紀》，今有榎葉井，《催馬樂歌譜》一名櫻井，在櫻井村）。上下佐味村。
# 餘戶（今小殿村，在大坂東南，卽其地），蓋安倍小殿氏所居（《續日本紀》）。

## 葛下郡

# 山直（今不詳），蓋山直族所居（《姓氏錄》）。慶雲中稱山君里，威柰大村墓誌（按山公氏居此，後賜姓曰直，鄕名從而改者，姑附備考）。
# 高額（今染野村，在神戶西北，卽此）。神功皇后妣稱葛城高額媛，蓋居于此（《日本書紀》、《古事記》）。有葛木倭文社（《延喜式》），委文宿禰所居（《姓氏錄》）。有大坂山口社（《延喜式》）。
# 賀美（今上里村，在高額）。
# 蓼田（今高田村，在郡東），古稱片鹽。有浮孔宮北（《日本書紀》，址在三倉堂村），後屬高市郡。
# 品治（今王寺村），品、王音相近，卽品治部所居（《日本書紀》、《古事記》、《續日本紀》）。古稱片岡（《日本書紀》），有片丘馬坂陵。有片岡社（《延喜式》），有片岡山，廏户太子逢眞人之處（《日本書紀》、《聖德太子傳暦》）。有肩岡池（今稱葦田池），推古帝所開（《日本書紀》）。有朝原（《古今和歌集》），有茅渟皇子葦田墓（《延喜式》），蓋葦田首貫此（《姓氏錄》，按葦田與朝訓相同）。壬申之亂，壹岐史韓國與吉野兵戰葦池側，卽此（《日本書紀》）。

## 宇智郡
下（《令義解》、《和名鈔》）。宇智與内音訓相通。按《姓氏錄》，孝元皇別有内氏，蓋居山城内地，因氏，後徙此。東南接吉野郡，西界紀伊伊都郡、河内石川郡，北連葛上郡（《大和志》）。領鄕四（《和名鈔》）。

# 阿陀（鄕名尚存，屬村十二，在郡東）。太國祖東征，自吉野至此，有苞苴擔子者，作梁取魚，因命餉軍，定爲阿太養鸕部（《日本書紀》、《古事記》，苞苴擔居址，今在阿陀村，土人尚業漁獵）。有阿陀比賣社（《延喜式》）。有阿太大野（《萬葉集》，在阿陀原村）。有藤原良繼阿陀墓（在南阿陀村）、藤原武智麻呂後阿陀墓（《延喜式》，在榮山寺北），後曰阿陀莊。有榮山寺（《榮出寺文書》，在小島村）。有荒木社（《延喜式》），有浮田杜（《大和志》，在今井村），所謂大荒木、浮田杜是也（《萬葉集》）。有靈安寺（《延喜式》，在靈安寺村）。弘和中有近内南莊（《二見氏文書》，今近内村），丹生川至此會吉野川（《大和志》）。

## 山邊郡
下（《令義解》、《和名鈔》）。承和中賜本郡地於宗康親王（《續日本後紀》）。東界伊賀、伊賀名張二郡，南至宇陀、城上二郡，西接城下、平羣二郡，北連添郡（都介又作竹谿，今山口）（《大和志》、《國圖》）。領鄕六（《和名鈔》）。

# 鞆田（諸村在郡中，英卽古鄕地）。古稱鬥鷄國，置造治之，允恭帝時廢。有鬬鷄野（又作都介野，在鞆田、甲岡二村）。仁德帝時大中彥皇子獵于此，得冰獻之，冰室實昉於此（《日本書紀》）。址在山田。天長以後定爲禁野（《三代實錄》）。有都介頓宮（址在甲岡村），伊勢齋王所宿（《江家次第》）。有都祁水分社、都祁山口社（《延喜式》）。靈龜元年開都祁山道。有掘越頓宫（址存甲岡東南向淵村），聖武帝嘗幸焉（《續日本紀》）。有神野山（《大和志》，在伏拜村上），方有神野寺，元慶四年敕修功德（《三代實錄》）。有波多橫山（在神野東北，稱仲峯山），旗野（《萬葉集》）。波多杣（《大安寺緣起》）。有神波多社（《延喜式》，古隸添上郡）。有名張川（《大和志》），孝德帝定畿内，東限名墾橫河，卽此（《日本書紀》）。
# 星川（今郡南吐山村有星川地），星川氏所居（《姓氏錄》）。有小原川、萩原。
# 服部（今新莊村有服部地），服部連所居（《姓氏錄》、《大和志》、《國圖》）。有引手山（《萬葉集》、《大和志》，在中村東，土人呼曰龍王）。
# 長屋（今郡西長原村有長屋原），卽名之遺。天曆中曰長屋莊（《東大寺要錄》）。有長屋原，和銅三年自藤原宮遷寧樂宫時，駐御輿於此（《萬葉集》）。有石上溝（在長柄村），履中帝時穿之（《日本書紀》、《大和志》），蓋長柄首所居。武内宿禰裔耳高居此，稱岸田氏（《姓氏錄》，今岸田村）。有手白香皇女衾田墓（在岸田東中山村）。有山邊御縣社（《延喜式》、《大和志》）。天暦中有山邊莊（《東大寺文書》），郡名起此。
# 石成（高山寺本成作生，其地不詳）。有石成社（《續日本紀》）。
# 石上（今磯上村，在長屋北），磯、石訓通，石上氏所貫（《日本書紀》、《舊事本紀》、《姓氏錄》）。有石上池（在磯上村），俗稱大將軍池。齊明帝六年，池上作須彌山像，以饗肅愼人（《日本書紀》）。有石上布留社（《延喜式》，按《日本書紀》作石上振神宫）。有布璢村（今布留村），布留氏所居（《姓氏錄》、《國圖》），後曰布留莊（《東大寺要錄》）。有振山（《萬葉集》）、布留川（《大和志》）。有石上神宮寺（《三代實錄》，在山口村東）。有石上寺（《後撰和歌集》，在布留村），稱良因寺，一名良峯寺（《相模家集》）。某光孝帝龍潜日嘗宿焉（《古今和歌集》）。有在原寺（《玉葉和歌集》，在磯上村）。有守部里（《萬葉集》，在布留西守目堂村田道閒），守裔橘守氏蓋居此（《古事記》、《姓氏錄》）。有石上穴穗宮（址在田村）、石上廣高宮（《日本書紀》、《大和志》，址在嘉幡村）。有淹知地（今菴治村），蓋倭淹知造所居（《古事記》、《姓氏錄》）。有三島莊（《西大寺田畠目錄》，今三島村），《錄大和志》。
