河内國  
大《延喜式》。
古曰：「凡河内」《日本書紀》、《古事記》，凡一作「大」，訓相通。有大河繞西北，故名。《河内志》、《河内國圖》。
太祖東征，至此勒兵《日本書紀》，既定天下，以彥已曾保理命爲國造《舊事本紀》。尋置志紀、紺口、三野、茅渟縣主，而丹比、長野、古市、樟葉、伊迦賀、櫻井、大戶、豐浦、額田、石川、日下、石津、更荒、坂本、高安、飛鳥、澀河、茨田、依網、狹山等地隸焉。參取《日本書紀》、《古事記》、《姓氏錄》。後立爲郡、爲鄕《延喜式》、《和名鈔》。
大化改制，管郡十八。《日本書紀》、《續日本紀》《和名鈔大意》。
和銅六年，省凡字《仙覺萬業鈔》。
靈龜二年，割其和泉、日根二郡，供珍努宮，尋加大鳥郡，號曰和泉監，後爲和泉國。
養老四年，并堅上堅下，曰大縣郡。
神護景雲三年，以由義宮爲西京，改河内職。
寶龜元年，復舊爲國。《續日本紀》。管郡十四，鄕八十。國府在志紀郡《延喜式》、《和名鈔》。《拾芥鈔》爲大縣郡。距京師行程一日《延喜式》。
東至大和，南界紀伊，西連攝津、和泉，北鄰山城。峯巒擁東南，淀川繞西北，大和川貫流之《河内志國圖》。後醍醐帝中興，以楠正成爲守護廣巖寺楠氏靈牌，《僧明極行狀》。後足利義滿以畠山義深代之《畠山系圖》。
 
## 錦部郡
小，《令義解》《和名鈔》。
初隸石川郡《日本書紀》本書仁德帝時，有石川錦織首，以地爲氏也，後建爲郡《和名鈔》。文武帝三年，本郡獻白鳩，詔免一年稅役《續日本紀》郡名始見。東至石川郡，南界紀伊伊都郡，西連和泉大鳥、和泉二郡，北接丹比郡《河内志國圖》。領鄕二《和名鈔》
# 餘戶
# 百濟。敏達帝卽位，宮于百濟大井。十二年，謀臣日羅爲百濟使人所害。敕置日羅妻子于石川百濟村，水手于大伴村，拘賊于下百濟阿田村，卽是有大澤嶺，石見川出。有鳩原，文武帝時，獲白鳩于此，故名。有石凝寺，建武中，有板持名，，古板茂連氏所居。有觀心寺，後村上帝所御。有觀心寺陵，有楠正成墳，正成戰死，賊送其首于鄕里，乃葬此。。有天野山，金剛寺在焉。正平中，車駕御此，號曰天野行宮。有金胎寺城，建武中，官軍所據。

## 古市郡
下。

# 新居。神龜中有下新居鄕宮處里。
# 尺度，今東西坂田村存在郡西南，古稱坂門，有坂門原陵。神龜中有尺度鄕鴨里，弘安中曰尺度莊，有利雁社，戶刈池，有壷井莊，源氏累世居此。
# 坂本。

# 三宅。

## 丹比郡
中。

# 大田邑。

## 和泉
和泉國
下。
古曰茅渟縣，隸於河内。太祖東征，皇兄五瀨命中流矢，至此洗創，因名。後置縣主治之，有男、石津、鳥取、曰根地屬焉。欽明帝時有泉郡，地出清泉，故名。靈龜二年置珍努宮，以和泉、曰根二郡供之，尋加大鳥郡，改稱和泉監。天平十二年停監，并于河内。天平寶字元年立曰和泉國，管郡如舊。天長二年管攝津江南四郡，無幾復故。鄕二十四。國府在和泉郡，距京師行程上二曰下，一日。東至河内，南界紀伊，西臨海，北連攝津。源賴朝以佐原義連補守護。後醍醐帝時以和田正武爲守。後足利義滿以山名氏清爲守護。明德中大内義弘代之。

## 大鳥郡
中。
東界河内丹比、錦部二郡，南接和泉郡，西至海，北連攝津住吉郡。領鄕十
# 大鳥，有大鳥社，大鳥連居此，大鳥社流記帳。延喜中，大鳥、高槻、菅町三里屬焉。正平中曰大鳥莊。有高石池，有高腳海，有高礒浦，高腳濱，有高石社，有所石頓宮，有取石池，蓋取石造、高志連二族所貫。
# 曰部。太祖東征，自浪速抵草香邑、白肩津，長髓彥逆戰，皇師植盾布陣，因號盾津，後訛曰蓼津，卽此。垂仁帝時五十瓊敷入彥命作曰下高津池。有曰部社、曰部驛，曰下部首貫于此。有菱城邑，有菱木祠，仁賢帝時有鹿父者居此。有鶴田池。
# 和田，和田首所居，仁治中鄕名尚存，正平中曰和田莊。有美多彌社，民直居此。有檜尾池。
# 上神，古神直貫于此，有國神社。櫻井社，有大庭寺，大庭造、櫻井朝臣蓋居此。有和田城。
# 大村，古曰陶邑，陶津耳命居此，有女曰活玉依姬，大已貴神通之，生櫛御方命，其曾孫曰大田田根子。崇神帝時有神教，召爲祭大已貴命神主，後更今名。有大村山，大村寺，有陶荒田社，大村直、荒田直居此。有陶山，貞觀中河内、和泉二國民爭採燒陶薪地，遣使檢勘，定屬本國。
# 土師，古曰石津原，仁德帝放鷹於此，後定爲陵地。時有百舌鳥咋鹿耳而殪之，因號曰百舌鳥耳原，有百舌鳥耳原中陵及北陵。土師連世居此，因爲鄕名，有土室地。文安中曰萬代莊，後曰土師保。有百濟凡人、中家地，蓋百濟凡人、中家二氏所居。
# 蜂田，有蜂田社，蜂田連、蜂田藥師貫于此，有蜂田寺，後曰八田莊，康正二年造内裏段錢引付。平井村稱茨池，有家原寺。
# 石津，有石津太社，石津連所居，有石津川，有百舌鳥耳原南陵。
# 鹽穴，有鹽穴寺，延元中曰鹽穴莊，有葦田里，葦田浦，有高渚院，按寶龜中施入本郡田三町，有界浦，後曰界南莊、界北莊。
# 常淩，有等乃伎社，卽中臣殿來連所居，後更深井，有香琳寺，寺有井曰深井，鄕名本此，有薦江池。

## 和泉郡
中。
東界河内錦部郡及紀伊那賀、伊都二郡，南接曰根郡，西抵海，北連大鳥郡。按《和名鈔》云：「國分置泉南郡。」《行基年譜》又有泉南郡，其來尚矣。《泉州志》曰：「國分猶曰私分，蓋國司隨便分之，不出朝命也。」領鄕十
# 信太，信太首居此，有信太森，正平中有信太城，有舊府社、聖社。
# 上泉，有和泉井，國名由起，後國府在焉，有和泉社，有泉井上社，傳言神功后行宮遺址也。後分爲二鄕，有珍縣主故居，有和泉宮，又曰智努離宮，元正、聖武二帝所幸。有二田地，二田物部所居。有曾禰社，有伯太地，蓋曾禰連、伯太首所居。興國中曰大泉莊。
# 下泉，有我孫村富祠，我孫公所居，有泉穴師社，有穴師池。按宮村舊名穴師，有大津浦，又稱小津泊，有大津川至此歸海，後曰今泉莊，又曰宇多莊。
# 輕部鄉，古曰加里鄉，八綱田命裔居此，雄略帝時獻本鄕，因賜姓輕部君，有輕部池，有玉井山莊，有和氣地，有和氣俱在小田村祠，和氣公所居。
# 坂本，有坂本祠，坂本朝臣所居，承和中其族居讚岐者請復和泉舊墟，卽此。
# 池田，池田首所居，後曰池田莊。有國分寺，承和中以安樂寺擬之，有施福寺，有橫山，慶雲中曰橫山鄕，有橫山莊，有松尾川、牛瀧川，有松尾寺，安元中有春木莊，有物部布畱祠，有物部田池，有膳部尾唐國地，膳臣、韓國連所居。
# 山直，有山直社，山直氏所居，有山直池。
# 畑八木，有夜疑社，八木造居此，有犬飼地，若犬養宿禰所居，有久米多池，有久米田寺，俱僧行基所開，有橘諸兄墓。嘉禎中有吉井鄕。
# 掃守，有掃守田祠，掃守田首所居，天授中曰加守鄉，有加守川，有雌雉田。安閒帝敕大河内直味張獻其地，味張悋而不進，因停其職。南朝時和田正成城此，改號岸和田。有松村里，國見山，有新治地。天平神護元年幸曰根郡新治行宮，卽此。
# 木島，有木島山，一名杣山，出良材，古爲橘諸兄采地，有有眞香邑，或有眞香、阿理莫，有阿理莫社，安幕首所居，有捕鳥部萬墓，墓北有犬冢，有神於山，葛城山，有麻生莊，永吉莊。

## 曰根郡
下。
東南界紀伊那賀、名草二郡，西臨海，北接和泉郡。貞觀中充本郡地於淳和院。領鄕四
# 近義，其土宜五加，因名，智木氏及近義首居此，有近義川，有熊取野行宮，延暦中帝遊獵于此，後曰熊取莊。文治中曰小木鄕，後曰古木莊。
# 賀美，有茅渟宮，允恭帝妃衣通郎姬居此，帝屢幸焉。有曰根野，郡名所起。雄略帝時根使主獲罪，逃於曰根，卽此。有曰根行宮，延曆中帝獵于曰根野。承和中遷河内丹比郡驛家院倉于此爲正倉。有曰根社，曰根造居此，有曰根松原，後曰曰根莊。有土丸城。後曰神野莊。
# 呼唹。五瀨命負創至山城水門，按劍雄誥，因名曰雄水門，後更今字。有雄山，延曆中幸紀伊，自雄山道還御日根行宮是也，有男社、呼唹驛。有佐野松原，澳津濱。有茅渟池，相傳五十瓊敷入彥命開，後曰布池。有垣田野，桓武帝嘗獵于此，有加支多社，有君池，相傳五十瓊敷入彥命造。有男里川。有信達行宮，後鳥羽院熊野御幸記作信達廏戶行宮。白河、堀河二上皇幸熊野，每御於此，後曰信達莊。
# 取，鳥取氏所居，因名，後曰鳥取莊。有菟砥川上宮，又號鳥取河上宮，五十瓊敷入彥命居此，造劍一千口，有宇度墓，卽葬皇子云。有鳥取山，有箱浦。所田身輪邑，田身載筥作莊，蓋此。邑有紀小弓宿禰夫妻墓。雄略帝時小弓任征新羅將軍，薨于軍，其妻上道大海護柩而還，敕土師連小鳥築墓於田身輪邑，卽此。寬正中曰淡輪莊，有紀船守墓。有黑埼松原，吹飯浦。有深曰行宮，天平神護中所置。有吹飯浦城，壽永中安摩忠景築之以應源氏，爲平敎經所破，後曰深曰莊。有橘逸勢及其女尼妙沖墓。有田無川，建久中曰谷川莊。
