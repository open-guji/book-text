上（《延喜式》）。古作“山背”（《日本書紀》。一作：山代）。在大和北，因名（《諸神記》、《山城志》）。天津彥根命裔世居此（《古事記》）。太祖以阿多根命任國造，即其後也（《舊事本紀》）。初有墮國、葛野、岡田、內、許國、大國、栗隈、筒城、懸木、賀茂、刈幡、羽振、苑地，皆屬本國（《日本書紀》、《古事記》、《山城風土記》、《萬葉集》）。後定爲郡、爲鄕（《延喜式》、《和名鈔》）。延曆遷都，詔曰：“山河襟帶，自然作城。據斯形勝，宜制新號。”因更今名（《日本紀略》）。管郡八，鄕七十八（《延喜式》、《和名鈔》）。國府在葛野郡，延暦中，徙乙訓郡（《日本紀略》）。東接近江，南至大和、河內、伊賀，西鄰丹波、攝津，北界丹波。羣巒圍三面，西南坦夷。琵琶湖下流自近江來，爲宇治川，容賀茂、葛野出水，三水會淀川，歷河內、攝津注海。景致秀麗，土厚水甘，勝境尤多（《山城志》、《山州名跡志》、《山城國圖》）。

文治中，源賴朝殲平氏，上皇敕源義經，留衛宮闕。賴朝弗懌，帥兵西上，義經遁，乃奏置京師守護，以經略近畿（《東鑑》）。承久以後，北條氏以陪臣執國命，置府于六波羅，掌京畿、山陰、山陽、南海政刑（《東鑑》、《太平記》）。元弘中，綱紀一振，諸制復舊。旣而足利尊氏反，帝出狩南山。尊氏乃擁立北主，建牙室町，以抗王師。七道糜沸，畿內喪亂，殆無寧歲（《保暦閒記》、《太平記》）。

## 乙訓郡
中（《令義解》、《和名鈔》）。古隸葛野，曰“墮國”。垂仁帝時，丹波竹野媛歸鄕里，自墮輿而死，因名。後曰“弟國”。繼體帝遷都於此（《日本書紀》）。和銅中，改今字（《續日本紀》、《延喜式》。弟國、乙訓，音訓相通）。東接紀伊郡，南至綴喜及攝津島上郡，西界丹波桑田郡，北鄰葛野郡（《山城志》、《國圖》）。領鄕九（《和名鈔》）。

# 山埼（今山埼驛，在郡東南）。有山埼驛（《類聚國史》、《延喜式》。按《凌雲集》，作河陽驛，在淀川北，故云）。有山埼社（《延喜式》）。山埼橋（《文德實錄》、《扶桑略記》）。其地與河、攝界，通山陽、南海、西海，頗爲要津（《三代實錄》、《本朝文粹》、《朝野羣載》）。弘仁四年，帝獵交野，以驛館爲行在，稱曰“河陽宮”，後屢幸焉（《類聚國史》，又稱“山埼離宮”）。貞觀三年，國言，河陽離宮，久絕行幸，請爲國司行政所，但存宮號，兼充行宮，制可（《三代實錄》）。有山埼山。後鳥羽帝嘗獵于此（《明月記》）。五位川出（《山城志》）。有相應寺（《三代實錄》）。有葛原親王墓（《山城志》，在圓明寺村。按古鄕區域，不可得而詳，及山川邑里，難的知其所屬者，今據地圖推攷方位，繫之各鄕下。又神名、諸陵二式所，舉地名，不保必無改遷，然無他書可徵者，就今所在，以證故地，下傚此）。
# 鞆岡（今友岡村，在山埼北）。土宜小竹（《神樂歌譜》、《枕草子》）。有木上山（《文德實錄》，在奧海印寺村）。狐川出（《夫木集》、《山城志》，今稱小泉川）。有海印寺（《文德實錄》）。保安中，有富坂莊（《三鈷寺文書》）。
# 長岡（刻本不載，今據高山寺本補。按《續日本紀》、《類聚國史》、《扶桑略記》及《山城志》、《國圖》，北自上里、寺戶，南亙神足、開田諸邑，蓋古鄕地）。延曆初，遷都于此（《續日本紀》）。有長岡野。天長中，定爲禁野（《三代實錄》）。有長岡園（《延喜式》）。長岡陵（《續日本紀》）。有典侍小野石子長岡第（址在上里村）。弘仁中，車駕幸于此（《類聚國史》）。後曰長岡莊（《三鈷寺文書》）。有寺戶莊、鷄冠井里（《今昔物語》、《三鈷寺文書》。今有寺戶、鷄冠井二村）。有島院（故址在白井村）。延曆初，設曲水宴（《續日本紀》）。有乙訓社、乙訓園（《延喜式》）。乙訓寺（《性靈集》，在今里村）。即古弟國地。繼體帝御宇於此（《日本書紀》）。
# 長井（今不詳）。承久中，有長井莊（《三鈷寺文書》）。
# 大江（今沓掛村，在郡西北，即古鄕地）。有大枝陵。後大枝陵（《延喜式》、《類聚符宣鈔》）。大枝氏貫于此（《姓氏錄》）。有大枝驛（《延喜式》。按本書繫丹波國，今老坂即此）以通丹波（《萬葉集》）稱曰“大枝道”（《續日本後紀》）。長寬中，鄕名尚存（《三鈷寺文書》）。有大原野（今大原野村）。桓武帝屢獵于此。天長中，定爲禁野。仁和中，爲陽成上皇遊獵地（《三代實錄》）。有大原野社（《二十二社注式》、《諸社根元記》）。物集（今物集女村，在郡北）。秦氏族物集氏所居（《姓氏錄》）。後曰物集莊（《仁和寺諸堂記》）。
# 訓世（或作國背，又來背。今上下久世村，在物集東）。蓋國背宍人居此（《姓氏錄》）。文永中，有久世莊（《東寺文書》、《三鈷寺文書》）。
# 榎本（今不詳。《山城志》有坂本村。按《姓氏錄》左京皇別有坂本朝臣，則榎疑坂字訛）。
# 羽束（今古川、志水諸村，在訓世東南，即古鄕地）。有羽束師社、羽束志園（《延喜式》）。有赤日埼（今赤井村）。桓武帝覽洪水于此。有赤日廏。宇多上皇遊獵御此（《日本紀略》）。弘安中，有赤日莊（《後宇多院御領目錄》）。正安中，有菱河莊（《東寺文書》。今菱川村）。有與杼社。有與等津，置官船（《延喜式》、《山城志》）。有久何社（《延喜式》）。久我里（《春雨鈔》。今上下久我村）。正治中，曰“久我莊”（《明月記》、《後宇多院御領目錄》）。有源雅定久我水閣，白河上皇幸焉（《中右記》）。有河原寺（廢址在菱川村）。大同初，幽伊豫親王母子（《日本紀略》）。
# 石作（今灰方、灰谷諸村，在物集西南，即其地。按高山寺本別有石川，蓋誤複也，故不取）。石作連所居，因名（《姓氏錄》）。有石作丘。桓武帝嘗畋於此（《類聚國史》）。有石作社、石作陵（《延喜式》）。石作寺（《三代實錄》）。有小鹽山（《古今和歌集》）。後曰“小鹽莊”（《桃花藥葉》、《三鈷寺文書》、《東寺丈書》。今小鹽村）。

## 葛野郡
上（《令義解》、《和名鈔》）。初稱葛野。應神帝幸近淡海，望人烟盛起，曰，是國之奧區也（《日本書紀》、《古事記》）。桓武帝亦謂，此地山川清麗，康莊四達，遂遷而都，號曰“平安京”（《日本紀略》）。東接愛宕郡，南鄰乙訓郡，西北界丹波桑田郡（《山城志》、《國圖》）。領鄕十二（《和名鈔》）。

# 橋頭（今唐橋村，蓋是）。延曆中，詔造佐比川橋（《日本後紀》）。鄕在其橋畔，因名（《國圖》參取《山城志》）。嘉祥中，朝原宿禰河雄居此（《東寺文書》）。後曰“唐橋里”（《二水記》。按《山城志》云：唐橋在唐橋村西南，昔蕃客入京，過此至鴻臚館，故名）。
# 大岡（今岡村，在郡南）。有大丘野（《續日本紀》）。大崗忌寸居此（《姓氏錄》）。有桓武藤原夫人大岡墓（《延喜式》，在御陵村）。
# 山田（今山田村，在大岡北）。元亨中，鄕名尚存（《興福寺官務牒》）。有松尾社、葛野坐月讀社、櫟谷社（《延喜式》）。顯宗帝時，有歌荒樔田（《日本書紀》）。有荒子山（《松尾鎭座記》，今作嵐山。按荒樔、荒子、嵐、邦讀同）。山多櫻樹，龜山上皇所植也（《新千載和歌集》、《山城志》）。有葛野川（《山城志》、《國圖》）。葛野堰（《政事要略》引《秦氏本系帳》及《令集解》）。大堰里。列聖遊幸弗絕（《山城志》）。有龜山（《本朝文粹》）。後嵯峨、龜山二上皇御此（《百鍊鈔》、《古今著聞集》）。足利尊氏就創天龍寺（《太平記》）。有小倉山莊。兼明親王所營（《後拾遺和歌集》、《山城志》）。有嵯峨野（在小倉山東）。元慶中，定爲禁野（《三代實錄》）。有嵯峨山上陵（《文德實錄》）。有嵯峨院。嵯峨上皇所御（《續日本後紀》）。貞觀中，捨爲大覺寺。有觀空寺，亦上皇所刱。有左大臣源融栖霞觀（按栖霞、嵯峨音通）。清和帝嘗幸此（《三代實錄》）。後曰“栖霞寺”（《本朝文粹》、《花鳥餘情》）。有嵯峨莊。（《東寺文書》。今上下嵯峨村）。有陶野。淳和帝嘗來畋（《類聚國史》）。有大澤池（《古今和歌集》）。廣澤池（《風雅和歌集》）。有仲野親王高畠墓（《延喜式》，在嵯峨中野村）。有水雄岡（在嵯峨西北）。寶龜中，車駕幸此（《續日本紀》）。有水尾山寺。清和上皇御此（《三代實錄》）。有愛宕山（在水尾北），阿多古社在焉，古屬丹波云（《延喜式》、《山城志》）。
# 川邊（今不詳）。嘉祥中，秦忌寸冬守所居（《東寺文書》）。
# 葛野（今稱郡、上野二村，曰葛野，在山田東）。太祖時，鴨建角身命裔，爲葛野縣主（《日本書紀》、《舊事本紀》、《姓氏錄》）。有葛野。桓武帝屢獵于此（《類聚國史》）。有梅宮社（《延喜式》）。有梅津里（《延久百首》，今梅津村）。梅津莊（《東寺文書》）。古郡家所在（《和名鈔大意》）。
# 川島（今河島村，在大岡東）。昌泰中，宇多上皇遊獵于此（《日本紀略》）。安貞中，曰“河島莊”（《東寺文書》）。有宇多外祖母當宗氏河島墓（《延喜式》，在德大寺村）。有桂里（今桂村）。相傳，太古月讀尊降葦原中國，詣保食神所，倚桂樹而立，因號桂里（《山城風土記》）。弘安中，曰“桂莊”（《後宇多院御領目錄》）。
# 上林（今龍安寺、北野諸邑，在郡東，即此）。大伴氏族林宿禰所居（《姓氏錄》）。有伴氏神社（《延喜式》）。承和中，賜本鄕地一町於伴宿禰，爲祭氏神所，即此（《續日本後紀》）。有北野社（《北野緣起》、《諸社根元記》）。平野社。有德岡冰室（《延喜式》，址在龍安寺村。住吉山）。衣笠山（一作絹笠岡，在龍安寺村）。有等持院（《太平記》）。鹿苑寺（《宣胤記》，世稱金閣）。紙屋川（《古今和歌集》、《山城志》）。
# 櫟原（按今上嵯峨，領町三、村六，蓋其地）。有櫟原野。嵯峨帝嘗獵于此（《類聚國史》）。元慶中，以本鄉地三町，賜興福寺僧修審（《三代實錄》。按本書修審牒云：機原鄉，本爲嵯峨院四至內。貞觀中，建大覺寺，定四至日，還爲公地，望請處分。於是詔賜之。大覺寺在上嵯峨，爲其故地，足徵矣）。高雄山，有神護寺（《類聚國史》、《神皇正統記》）。栂尾山，有高山寺，僧高辨始栽茶于此（《海人藻芥》、《酒茶論》）。
# 高田（今高田村，在山田東）。嘉祥中，有鄉長高田部某（名闕）。天永中，鄉名尚存（《東寺文書》）。有廣隆寺（《廣隆寺緣起》），所謂葛野秦寺也（《日本書紀》）。有木島社（《延喜式》）。
# 下林（今下林村，在川島南）。有川勝寺（址在川勝寺村）。有津寺（《山城志》，在川勝寺西）。延曆中，帝巡覽新京，御右大臣藤原繼繩高橋津第，即此（《類聚國史》）。
# 緜代（今不詳）。
# 田邑（今御室、中野、宇多野諸邑，在上林西，即其地）。有田邑陵。後田邑陵（《延喜式》）。有眞原岡（《三代實錄》）。小松原（《延喜式》）。有雙丘。淳和帝嘗遊畋（《類聚國史》）。有雙池（《後撰和歌集》）。仁明帝屢放鷹于此（《續日本後紀》）。有雙丘寺（《三代實錄》，今稱寶金剛院）。寺有邱，稱五位冢，仁明帝登覽勝景，敕授從五位下，故名（《續日本後紀》、《山城志》）。有大內山（《扶桑略記》、《詞花和歌集》）。一名御室山（《續後撰和歌集》）。有仁和寺（《扶桑略記》）。有宇多野（《類聚國史》）。宇多冰室（《新後撰和歌集》）。有鵜原寺（《三代實錄》、《延喜式》）。鵜原冰室（《朝野羣載》，竝在平岡村）。有鳴瀧里（《扶桑略記》）。鳴瀧川出（《山家和歌集》，今鳴瀧村，舊稱小松莊）。

## 愛宕郡
中（《令義解》、《和名鈔》）。蓋古久我國也（《山城風土記大意》）。後爲郡，更今名（《延喜式》）。東至宇治郡，及近江滋賀郡，南連紀伊郡，西接葛野郡，北界丹波桑田郡，及近江高島郡（《山城志》、《國圖》）。領鄕十一（《和名鈔》）。

# 蓼倉（按一書云：蓼倉鄕田中里，今田中村，在京城東北，即其遺名）。寬仁中，鄕名尚存（《類聚符宣鈔》、《賀茂注進雜記》）。後曰“蓼倉莊”（《永享四年文書》、《花洛往古圖》）。有賀茂御祖社、三井社（《延喜式》、《釋日本紀》）。有法雲寺（《薩戒記》，一名“蓼倉藥師堂”）。有白川（《古今和歌集》）。
# 栗野（今御栗栖野，在蓼倉西北，即名之遺）。有栗栖野。桓武帝獵于此（《類聚國史》）。天長中，定爲禁野（《三代實錄》）。有緜子池（在西賀茂村。曰池田）。仁明帝幸此放隼（《續日本後紀》）。有栗栖野冰室（《延喜式》，今冰室村，在鷹峯北）。有高岑寺（《三代實錄》）。紙屋川出（《山城志》）。
# 粟田（刻本爲上粟田、下粟田二鄉。《類聚符宣鈔》、小右記亦同，是後世之爲，非古制也。今從高山寺本訂。但本書註有上下二字，是謂鄉有上粟田、下粟田二里，與下條出雲鄕例同。今粟田口、北白河諸邑，即其域也）。粟田氏所居（《姓氏錄》）。後曰“粟田莊”（《永享中文書》）。有粟田院。藤原基經故居。元慶中，清和上皇御此，遂捨爲圓覺寺（《三代實錄》）。有粟田殿。藤原在衡別業（《拾芥鈔》）。有白河陵。有清和外祖母源氏墓（《延喜式》）。有白河院。藤原良房別業（《簾中鈔》、《古今榮雅鈔》）。白河帝就建法勝寺，以爲離宮（《百鍊鈔》、《簾中鈔》、《應仁記》）。有南禪寺（在法勝寺東），爲龜山上皇離宮，後捨爲寺（《南禪寺記》）。有禪林寺（《三代實錄》、《山城志》，在南禪寺北）。又爲龜山上皇離宮（《南禪寺記》）。有康樂岡（一作：神樂岡）。桓武帝嘗獵于此（《類聚國史》）。有吉田社（《二十二社注式》）。粟田山（《文德實錄》、《三代實錄》）。巓有將軍冢。延曆中，敕埋，偶像擐甲胄帶弓矢者，以鎭皇城（《田邑傳記》）。
# 大野（今大宮村，在栗野南，即古鄉也）。寬仁中，以本鄕充賀茂祭田（《類聚符宣鈔》、《賀茂注進雜記》）。有紫野。桓武帝獵于此（《類聚國史》）。有大德寺。花園帝所創（《大德寺文書》）。有船岳。貞觀中，祈晴于此（《三代實錄》）。有雲林院（一名紫野院），淳和帝離宮也（《類聚國史》、《離宮據河海鈔》）。仁明帝亦御此（《續日本後紀》）。後賜常康親王，遂爲佛寺（《三代實錄》）。有小野篁墓（《河海鈔》、《山城志》，在雲林院南）。
# 小野（今高野村有小野社，即其地）。小野朝臣世居此南（《三代實錄》，高野村有小野毛人墓）。有小野社、小野冰室（《延喜式》。按《朝野羣載》作松埼冰室。今有松埼村）。御蔭山（《小右記》，本書作“小野鄉大原”。御蔭山，又稱御生山）。有比叡山，跨近江（《古事記》、《叡岳要記》、《國圖》）。其西麓爲小野山（《小右記》、《山城志》）。音羽川出（《拾遺和歌集》、《八雲御鈔》）。有南淵年名小野別業（《古今著聞集》、《山城志》，今修學院村。有赤山社，即其址）。有八瀨里（《類聚符宣鈔》、《小右記》）。大原里（《拾遺愚草》、《山城志》、《河海鈔》作“小野鄉大原村”。今大原莊，屬邑八）。有惟喬親王小野山莊（《古今和歌集》，址在上野村）。有江文山（《元亨釋書》，在井出村）。松埼川。弘仁元年禊于此（《類聚國史》）。有伊佐彌里（《三代實錄》、《山城志》。今稱花園村，在八瀨西）。八鹽岡（《新敕撰和歌集》）。
# 錦部（按《類聚三代格》云：本鄕百姓言，鴨河堤東西水陸田，則我等口分，事具圖籍。《兵範記》云：錦織鄕吉田村。據此，吉田村以西至京師，古鄕地也）。錦部首所居（《姓氏錄》）。寬仁中，以本鄉充賀茂社祭田（《類聚符宣鈔》）。建長中，有吉田泉殿，後嵯峨上皇幸焉（《百鍊鈔》）。
# 八坂（今八坂町）。八坂造所居（《姓氏錄》）。有光孝外祖母藤原氏八坂墓（《延喜式》，在八坂法觀寺北）。有祇園社（《諸社根元記》）。有八坂寺（《續日本後紀》、《拾芥鈔》。一名法觀寺）。清水寺（《百鍊鈔》、《東寶記》，在八坂東南）。
# 鳥戶（今新熊野村旁近，即其地）。有鳥部山（其巓曰：“阿彌陀峯”）。有鳥部寺。鳥部野（《日本紀略》、《扶桑略記》、《山城志》）。有鳥部野陵（《三代實錄》）。有恒世、實仁二親王鳥部野墓（《日本紀略》、《扶桑略記》）。藤原總繼拜志墓（《延喜式》、《山城志》）。有清閑寺（《百鍊鈔》、《拾芥鈔》，在清閑寺村）。有泉涌寺（《元亨釋書》、《薩戒記》，在泉涌寺村）。其後山稱“月輪山”。四條帝以後，列聖山陵多在此（《前王廟陵記》、《山陵志》、《山城志》）。有法住寺。後白河上皇所營（《山槐記》）。
# 愛宕（今八坂西有愛宕寺，即名之遺）。古者郡家所在（《和名鈔大意》）。延曆中，定爲諸臣墓地（《河海鈔》引《延曆遷都記》）。有愛宕寺（《河海鈔》、《伊呂波字類鈔》，一名珍皇寺）。有建仁寺（《百鍊鈔》）。六波羅密寺（《本朝文粹》、《扶桑略記》引《往生記》）。有六波羅第，平氏世居此（《山槐記》、《東鑑》、《百鍊鈔》）。源賴朝亦第于此。承久以後，北條氏就置二廳，稱曰南北六波羅（《東鑑》、《百鍊鈔》、《太平記》）。
# 出雲（原註曰：有上下。按《東大寺正倉院文書》，鄉有雲上里、雲下里，故云。今下賀茂西有出雲寺址，即其遺名）。神龜中，出雲臣居此（《東大寺正倉院文書》）。有出雲井於社（《延喜式》）。出雲寺（《智證年譜》）。
# 賀茂（今有上賀茂、西賀茂二村，在栗野東）。上古賀茂建角身命，自岡田賀茂，沿山代川而上，望賀茂川曰：“何水石之清也？”因曰“石川”、“瀨見小川”，遂居久我國北山，即此（《山城風土記》）。太祖時，其裔爲葛野鴨縣主，子孫因氏焉（《舊事本紀》、《姓氏錄》）。有賀茂別雷社（《延喜式》）。賀茂、高野二水會此，南入淀川（《山城志》、《國圖》）。有泥濘池（在鴨山東）。淳和帝嘗羅水禽于此（《類聚國史》）。有小鹽山。山下曰“芹生里”。有寂光院。建禮門院所居。大原陵在焉（《源平盛衰記》、《長門本平家物語》）。有貴布禰社（《延喜式》）。貴布禰山（《夫木集》）。貴布禰川出（《千載和歌集》、《山城志》）。有鞍馬寺（《元亨釋書》、《伊呂波字類鈔》，在鞍馬山）。源義經幼寓此（《平治物語》、《源平盛衰記》）。有久多莊（《醍醐三寶院文書》，在鞍馬山東，屬邑五）。靜原里（《山家和歌集》，今靜原村）。

## 紀伊郡
中（《令義解》、《和名鈔》）。古稱許國（《山城風土記》，按許、木，音訓通。和銅中，定爲紀伊）。東至宇治郡，南接久世郡，西連乙訓、綴喜二郡，北界愛宕、葛野二郡（《山城志》、《國圖》）。領鄕八（《和名鈔》）。

# 岡田（今東福寺前有地名岡田，即其遺也）。有法性寺（《日本紀略》，址在東福寺前）。東福寺（《元亨釋書》、《東福記年錄》）。有藤原兼實月輪墓，即其別業所在（《明月記》、《類聚大補任》）。
# 大里（今西莊村，在郡西北，蓋古鄕地）。養老中作邑，薩茨田連居此（《東大寺奴婢籍帳》）。
# 紀伊（按《文德實錄》遣使深草陵近鄰七寺，修先帝冥福，中有紀伊寺。據此，本鄉蓋在深草比鄰，可知矣）。有紀伊寺（《文德實錄》、《廣隆寺緣起》。一名“隆城寺”）。古郡家在焉（《和名鈔大意》）。
# 鳥羽（今上下烏羽村，在郡西）。寬治中，白河上皇營離宮，號曰“鳥羽殿”，門牆亙方百餘町，窮極華麗，公卿第宅，鱗次櫛比，儼如新都（《扶桑略記》、《百鍊鈔》）。先是上皇皆御朱雀院，稱曰“後院”，至是以此定爲後院（《神皇正統記》）。有安樂壽院（《山槐記》，在竹田村。一名城南寺）。後曰“鳥羽莊”（《管見記》、《東寺文書》。按古歌所謂烏羽田，即此）。元中中。有竹田莊（《東寺文書》）、三栖莊（《後宇多院御領目錄》、《東寺文書》、《袖中鈔》）。有芹川野（今芹川村）。桓武帝屢獵于此（《類聚國史》）。天長中，定爲禁野（《三代實錄》）。後曰“芹川莊”（《東寺文書》、《袖中鈔》）。
# 石原（今有石原村，在鳥羽西北）。嘉元中，曰“石原莊”（《三鈷寺文書》）。有賀陽親王石原家。有佐比寺（《三代實錄》，址在吉祥院村）。有佐比川。弘仁中，幸此修禊（《日本紀略》）。
# 拜志（今不詳）。有拜志寺（《文德實錄》）。承安中，有“拜師莊”（《東寺文書》）。有眞幡寸社（《延喜式》）。
# 深草（今深草村，在鳥羽東）。欽明帝時，秦大津父居此（《類聚國史》）。皇極帝時，置深草屯倉（《日本書紀》）。有深草山（《類聚國史》）。霞谷（《古今和歌集》、《山城志》）。有深草陵。後深草陵，及陽成外祖母藤原氏深草墓。有稻荷社（《延喜式》）。後曰“稻荷莊”（《東寺康正二年文書》）。有竹葉山（《新敕撰和歌集》、《山城志》）。
# 石井（高山寺本不載，今石井村，在深草南，屬伏見）。古稱俯見村（《日本書紀》）。有伏見莊（《毘沙門堂記錄》）。伏見山（《増鏡》、《風雅和歌集》）。伏見津（《東鑑》）。伏見澤（《新拾遺和歌集》，今稱大池）。有伏見離宮。建長七年，後嵯峨上皇幸此（《百鍊鈔》、《太平記》、《椿葉記》）。有柏原野，桓武帝所遊獵（《類聚國史》）。柏原陵在焉（《延喜式》）。

## 宇治郡
（一作“宇遲”，又菟道）中（《令義解》、《和名鈔》）。初隸許國（《山城風土記大意》）。東北界近江滋賀郡，南接久世郡，西連愛宕、紀伊二郡（《國圖》）。領鄕八（《和名鈔》）。

# 大國（今不詳）。垂仁帝時，有山代大國之淵（《古事記》淵，《日本書紀》作不遲）。
# 賀美（今上野村，在郡北）。天平中，有賀美鄉戶主宇治宿禰大國。有堤田村（《東大寺古文書》、《山科古圖》）。有諸葉山（《夫木集》、《源平盛衰記》，在四宮村。曰“柳山”）。四宮川。袖河原（《夫木集》）。
# 岡屋（今有岡屋村，旁近七村，稱五箇莊，在郡西南，是其地）。岡屋公所居（《姓氏錄》）。後曰“岡屋莊”（《慈惠遺告》）。有岡屋野，桓武帝嘗獵于此（《類聚國史》）。有岡屋堂（《山科古圖》）。二子冢（《台記》）。
# 餘戶（今四宮東有餘古木村，屬近江滋賀郡，蓋此）。
# 小野（今小野村，在岡屋北）。後曰“小野莊”（《醍醐三寶院文書》、《源平盛衰記》）。有藤原高藤小野墓。宮道氏後小野墓（《延喜式》）。有勸修寺（《日本紀略》，在勸修寺村）。有小野陵。後山科陵（《延喜式》）。有醍醐寺（《伊呂波字類鈔》、《元亨釋書》，在醍醐村）。貞觀中，有笠取莊，爲醍醐寺領（《醍醐寺雜事記》、《三寶院文書》）。有日野（今日野村，在笠取西）。桓武帝所獵（《類聚國史》、《國圖》）。
# 山科（按《山科古圖》，南至小野鄕，東至近江界，北繞加美鄉，西至愛宕郡）。有山科野，中宗所遊獵（《日本書紀》）。有山科陵（《延喜式》）。有鏡山（《萬葉集》，在陵北）。延曆中，有山科驛（《日本後紀》）。後置山科園（《延喜式》）。山科川出（《山城志》）。有山階寺（址在東野村）。中臣連鎌子所刱（《扶桑略記》、《帝王編年記》。本書作：山階陶原）。有山階離宮（址在大宅村）。治承中，白河上皇所御（《百鍊鈔》）。後曰“山科莊”（《三寶院文書》）。有音羽里（《山科古圖》，今音羽村）。音羽山（《古今和歌集》）。音羽瀧（《夫木集》）。正平中，曰“音羽莊”（《三寶院文書》）。有元慶寺（《三代實錄》、《延喜式》作：花山寺）。坂上田村麻呂墓在焉（《田村傳記》）。
# 小栗（今南北小栗栖村在，小野西南）。後曰“栗栖里”（《山科古圖》）。有木幡村（《古事記》。按《政事要略》作小栗栖鄕木幡村）。應神帝幸近淡海，途御和珥臣祖日觸家，納其女宮主宅媛，生菟道稚郞子（《日本書紀》、《古事記》）。有許波多社（《延喜式》）。強田山（《萬葉集》。強田、木幡同訓）。有淨妙寺（一名木幡寺）。藤原道長所建（《政事要略》、《道長公記》、《小右記》）。凡藤原氏爲皇后及大臣者，多葬于此，稱曰“宇治陵墓”（《延喜式》、《政事要略》）。有木幡野。天長中，定爲禁野（《三代實錄》）。有伊豫親王巨幡墓（《延喜式》，在紀伊郡六地藏村）。後曰“木幡莊”（《源平盛衰記》）。長和中，有石田莊，爲醍醐寺領（《醍醐寺雜事記》，今石田村）。
# 宇治（今宇治町，屬邑五，在岡屋東南）。舊曰“許國”。菟道稚郞子，築桐原日桁宮居焉，因改今名（《山城風土記》）。武内宿禰之討忍熊王，屯兵于此（《日本書紀》）。有宇治社、宇治彼方社（《延喜式》）。有今木嶺（《萬葉集》）。朝日山（《新古今和歌集》）。山有宇治墓（《延喜式》）。即葬菟道稚郞子（《日本書紀》）。有槇尾山（《續後拾遺和歌集》）。三室戶山（今在三室村。名明星山）。阿後尼原（《萬葉集》，今三室村蜻蛉野，蓋此）。有宇治川，發琵琶湖，西會淀川（《山城志》、《國圖》）。出冰魚，置網代司貢之（《延喜式》、《侍中羣要》）。弘安中，僧睿尊立石塔，刻網代官符（《帝王編年紀》，塔在宇治橋南）。有宇治津（《延喜式》）。宇治橋（《續日本紀》）。嘉祿中，曰“宇治莊”（《東大寺續要錄》）。蓋古者郡家所在（《和名鈔大意》）。

## 久世郡

# 殖栗（今不詳）。殖栗連所居（《姓氏錄》）。
# 栗隈（高山寺本作“栗前”，今大久保村有栗隈杜，即遺名）。古曰“栗隈縣”（《日本書紀》）。有栗前野，桓武、嵯峨二帝屢遊獵（《類聚國史》、《日本後紀》）。天長中，定爲禁野（《三代實錄》）。有栗隈山（後稱栗子山，又作栗籠）。仁明帝獵于此（《續日本後紀》）。有栗隈天神祠（《興福寺官務牒》）。有栗隈渠（址在長池町）。仁德帝時，開以漑田，推古帝時，又疏之（《日本書紀》）。

# 拜志（今林村，在郡中央）。
# 久世（今久世村，在拜志東南）。有久世鷺坂（《萬葉集》。一作鷺坂山）。弘安中，曰“久世莊”（《後宇多院御領目錄》、《桃花藥葉》）。有久世川（《山城志》）。有小篠峯（《堀河百首》、《藻鹽草》）。古者郡司治于此（《和名鈔大意》）。
# 列栗（刻本作“羽栗”，誤。高山寺本不載。按《東寺天平中文書》有列栗鄕。《延喜式》有雙栗社。列、雙同訓）。竝栗臣居此（《東寺文書》）。有雙栗社（《延喜式》）。有狹山江御廚（《類聚雜要鈔》）。後曰“佐山莊”（《太子傳玉林鈔》、《興福寺官務牒》。今佐山莊，屬村十一）。有美豆牧（《袖中鈔》、《拾玉集》、《藻鹽草》，今御牧村）。美豆廏（《延喜式》）。有瑞野（瑞，一作箕津。今御牧西有美豆村，屬綴喜郡）。桓武、嵯峨二帝屢獵于此（《類聚國史》）。天長中，定爲禁野（《三代實錄》）。

## 綴喜郡
（一作管木，又筒城）中（《令義解》、《和名鈔》）。東界近江栗太郡，南至相樂郡，西連河內交野郡，北接久世、紀伊二郡（《國圖》）。領鄕十（《和名鈔》）。

# 山本（今山本村，在郡南）。和銅中，有山本驛（《續日本紀》）。有區毗丘（《類聚國史》，在飯岡村）。古稱馬咋山（《萬葉集》）。有咋岡社（《延喜式》）。正應中，曰“飯岡莊”（《西大寺田富目錄》、《今昔物語》作飯岳）。
# 多河（今多賀村，在山本東北）。有高社（《延喜式》）。有贄野池（《蜻蛉日記》、《源平盛衰記》。贄一作新。今在多賀西南，稱地藏池）。後曰“安堵莊”（《醍醐三寶院文書》。本書曰：多賀鄉安堵莊）。

# 中村（今有中村，隸久世郡）。
# 志磨（今柰島村，在多河西，蓋是）。有棃閒宿，市野邊山（《太平記》、《國圖》）。
# 綴喜（今普賢寺莊，屬邑十，在志磨西南，即其地）。開化帝孫大筒木眞若王所居（《古事記》）。繼體帝遷都于此（《日本書紀》）。有管木原（《萬葉集》）。筒城岡。有筒城宫（址今存）。仁德皇后磐之媛居焉（《日本書紀》）。韓人奴理能美家此，帝及皇后幸焉（《古事記》）。有朱智社（《延喜式》）。後曰“朱智長岡莊”（《興福寺官務牒》）。有普賢寺川（《山城志》）。亦古郡家之所在（《和名鈔大意》）。
# 大住（今大住村，在綴喜北）。大隅隼人居此，因名（《續日本紀》、《康富記》）。嘉禎中，有大住莊（住一作隅）薪莊（《東鑑》、《百鍊鈔》、《東大寺要錄》）。有甘南備山，出水晶（《山城志》、《國圖》，在大住西南）。有多柰久良野（《萬葉集》）。棚倉孫社在焉（《延喜式》）。有伽和羅邑（今河原村）。武埴安彦之死，敗卒棄甲而逃，因名（《日本書紀》。甲訓爲伽和羅）。有松井村（在河原西北）。天平神護中，絞紀益女于此（《續日本紀》）。

# 甲作（今不詳）。靈龜中，山背甲作部所居（《續日本紀》、《令集解》）。
# 餘戶（今不詳）。

## 相樂郡
下（《令義解》、《和名鈔》）。東界伊賀阿拜郡，南連大和添上、添下二郡，西鄰河內交野郡，北至綴喜郡，及近江甲賀郡（《國圖》）。領鄕七（《和名鈔》）。

# 相樂（今相樂村，在郡西南）。垂仁帝時，竹野媛過此，將攀樹而縊，故稱懸木，後更今字（《古事記》參取《日本書紀》。懸木、相樂，音訓相通）。即郡家在焉（《和名鈔大意》）。有相樂社（《延喜式》）。相樂山（《萬葉集》）。相樂頓宮（《江家次第》，址在枝村東，呼蜻蛉平）。有藤原百川相樂墓。藤原氏後相樂墓（《延喜式》，竝在吐師村，稱長冢）。後曰“相樂莊”（《東大寺要錄》）。有山田寺（《興福寺官務牒》）。有鹿背山（《萬葉集》。一作駕世，又挊）。有橘清友加勢山墓（《延喜式》）。有圓提寺（《類聚國史》，竝在鹿背山村）。
# 水泉（今木津村，隸甕原鄕，屬邑九）。又作出水（《興福寺官務牒》）。有泉川，舊名輪韓河。彦國葺之討埴安彦，夾河相挑，因號挑河，後訛曰“泉川”（《日本書紀》，今稱木津川）。有泉川渡（《中右記》、《續古事談》）。出水連居此（《姓氏錄》）。和銅中，置甕原離宮（址在岡埼井、平尾二村閒）。元明、聖武二帝屢幸焉（《續日本紀》）。後分曰“泉莊”、“甕原莊”（《東大寺文書》、《東大寺要錄》）。有國分寺（《續日本紀》，在登大路村）。海住山寺（《興福寺官務牒》，在佛生寺村，號出水山）。有布當山、布當野（《萬葉集》，屬井平尾村）。福當造居此（《姓氏錄》）。有和束山（《萬葉集》）。和束杣（《興福寺官務牒》，在杣山村）。有和束川（《山城志》。一名布當川）。後曰“和束莊”（《北野社文書》，屬邑十五）。有鷲峯山（《増鏡》、《太平記》，界綴喜郡）。
# 賀茂（今賀茂鄕，屬村六）。上古賀茂建角身命，自大和葛木山，遷居岡田之賀茂，即此（《山城風土記》）。岡田，後分曰賀茂鄉、恭仁鄕（《山城風土記》、《續日本紀》、《延喜式》）。和銅中，有岡田離宮，元明帝幸此。有岡田驛（《續日本紀》）。有岡田山。貞觀中，置採銅使鑄錢（《三代實錄》，今錢司村）。有岡田鴨社（《延喜式》）。後曰“加茂莊”（《扶桑略記》、《東大寺要錄》）。有岡田國社（《延喜式》）。是爲恭仁鄕（《續日本紀》、《延喜式》、《山城志》）。聖武帝營新宮，天平十三年，受朝賀於此，名曰“大養德恭仁宮”。按“大養德”即“大和”，中國總稱也，故冠之。恭仁，《萬葉集》作久邇，又稱布當宮。其地亙賀茂、甕原、木津、上狛諸鄉，從鹿背山西道以東爲左京，以西爲右京，開大路，架大橋，東北通近江甲賀郡云。十八年廢宮，以大極殿施國分寺（《續日本紀》）。恭仁鄕亦廢（《和名鈔》）。寬平中，有鹿鷺鄉（《類聚符宣鈔》）。後曰“笠置莊”（《宣胤記》。鹿鷺、笠置，邦讀同）。延喜中，有鹿鷺園（《延喜式》，今鷲峯山下有園村）。有笠置寺（《今昔物語》），後醍醐帝嘗避賊于此。有笠置山（《太平記》）。笠置川（《山城志》）。有大川原社。有市社（《三代實錄》）。
# 大狛（今上狛村，一名大狛）。大狛造所居（《日本書紀》、《姓氏錄》）。欽明帝時，居高麗使人于高楲館，即此（《日本書紀》，址在上狛村）。後曰“狛鄕”（《興福寺官務牒》）。又“狛野莊”（《東大寺續要錄》）。有狛山（《萬葉集》）。狛濟。土宜瓜（《催馬樂歌譜》）。有高麗寺（《日本靈異記》，址在上狛法華野）。有泉大橋，僧行基所創，置泉橋寺管之（《三代實錄》、《類聚三代格》、《行基年譜》。《年譜》作大狛村泉橋院）。天平十七年，車駕至恭仁京泉橋，是也（《續日本紀》）。
# 蟹幡（高山寺本不載。按《東大寺延暦中文書》有蟹幡鄕。今綺田村）。垂仁帝妃刈羽田刀辨，蓋居此（《古事記》。《日本書紀》作“綺戶邊”。綺、刈幡、竝與蟹幡訓相通）。有綺原社（《延喜式》）。雁羽野（《萬葉集》）。有蟹滿寺（《今昔物語》、《元亨釋書》，一名“紙幡寺”。二書竝爲久世郡）。有和支社（《延喜式》）。埴安彥之敗，士卒至此，知其不免，叩頭曰我君，因名我君邑（《日本書紀》）。後更今字（《延喜式》）。有光明山（《東鑑》、《元亨釋書》）。以仁王墓在焉（《山城志》，在綺田東南。鳥居邑）。有玉井頓宮（址在石垣村）。天平十二年，車駕幸此（《續日本紀》）。後曰“玉井莊”（《東大寺要錄》，本書繫綴喜郡。今綴喜郡，有井手莊）。有井堤鄕、井堤寺（《興福寺官務牒》）。有井手玉川（《新古今和歌集》）。井手山（《夫木集》）。
# 祝園（高山寺本不載，今祝園村，在大狛西）。彥國葺破埴安軍於輪韓河，屠戮靡遺，因號曰“羽振苑”（《日本書紀》、《古事記》。羽振，屠也。祝其假借，所謂取嘉名也）。有祝園社（《延喜式》）。後曰“祝園莊”（《北野社文書》、《東寺文書》、《西大寺田畠目錄》）。
# 下狛（高山寺本不載。今下狛村，在祝園西）。欽明帝時，置高麗俘虜，因名（《三代實錄》）。狛人野氏居此（《姓氏錄》）。後曰“下狛莊”（《興福寺官務牒》）。有和氣王狛野墓（《續日本紀》，在下狛村）。有稻八閒里屬此（《興福寺官務牒》、《體源鈔》）。即稻蜂閒連所居（《續日本紀》、《興福寺官務牒》）。正應中，曰“稻松葉莊”（《西大寺田畠目錄》。按八閒、松葉訓相近）。有藏滿祠（《興福寺官務牒》）。
