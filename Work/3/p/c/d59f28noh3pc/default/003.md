　　　　<臣|>等謹案尚書注疏十九卷漢孔安國傳唐
　　　　孔頴達疏漢初惟傳伏生今文尚書二十八
　　　　篇後安國得壁中書較多於伏生所傳又其
　　　　字體與漢𨽻異是為古文永嘉之亂古文中
　　　　絶晉梅賾乃上古文尚書四十五篇並安國
　　　　所作傳識者疑之頴達作正義專主安國翻
　　　　疑康成等所見古文為偽書何也晁公武謂
　　　　其因梁費甝疏廣之盖六朝諸家尚書義疏
　　　　世多不傳惟是書猶存其崖畧云乾隆四十
　　　　二年八月恭校上
