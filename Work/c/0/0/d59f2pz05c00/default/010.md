舍利弗。是眾生如是供養禮拜得無量福德。若欲得聲聞地。欲得辟支佛地。欲得阿耨多羅三藐三菩提者。當禮十方諸佛。一切皆得。復作是言。是諸福德聚諸佛如來所知。我悉回向阿耨多羅三藐三菩提。
