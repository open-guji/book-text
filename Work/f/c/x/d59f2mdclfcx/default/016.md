穀水出宏農黽池縣南墦塚林穀陽谷
山海經曰傅山之西有林焉曰墦塚穀水出焉東流注於洛其中多㻒玉今穀水出於崤東馬頭山穀陽谷東北流歴黽池川本中鄉地也漢景帝三年<一清按漢志是景帝中二年>初城徙萬户為縣因崤黽之池以目縣焉亦或謂之彭池故徐廣史記音義曰黽或作彭穀水出處也穀水又東逕秦趙二城南司馬彪續漢書曰赤眉從黽池自利陽南欲赴宜陽者也世謂之俱利城耆彦曰昔秦趙之㑹各據一城秦王使趙王鼓瑟藺相如令秦王擊缶處也馮異又破赤眉於是川矣故光武璽書曰始雖垂翅回溪終能奮翼黽池可謂失之東隅收之桑榆矣穀水又東逕土崤北所謂三崤也穀水又東左㑹北溪溪水北出黽池山東南流注於穀疑即孔安國所謂澗水也穀水又東逕新安縣故城南北夾流而西接崤黽昔項羽西入秦坑降卒二十萬於此國滅身亡宜矣穀水又東逕千秋亭南其亭壘石為垣世謂之城也潘岳西征賦曰亭有千秋之號子無七旬之期謂是水也又東逕雍谷溪回岫縈紆石路阻峽故亦有峽石之稱矣崤水歴側左與北川水合水有二源並導北山東南流合成一水自乾注巽入於穀穀水又東逕缺門山山阜之不接者里餘故得是名矣二壁爭高斗聳相亂西瞻雙阜右望如砥穀水自缺門而東廣陽川水注之水出廣陽北山東南流注於穀南望微山雲峯相亂穀水又逕白超壘南戴延之西征記云次至白超壘去函谷十五里築壘當大道左右有山夾立相去百餘步從中出北乃故闗城非所謂白超壘也是壘在缺門東一十五里壘側舊有塢故冶官所在魏晉之日引穀水為水冶以經國用遺迹尚有穀水又東石黙溪水出微山東麓石黙溪東北流入於穀穀水又東宋水北流注於穀穀水又東逕魏将作大匠毌丘興盛<一清按魏書毌丘儉□及裴松之注引魏名臣奏議張既表俱作毌丘興無盛字>墓南二碑存焉儉父也管輅别□曰輅嘗隨軍西征過其墓而歎謂士友曰□武藏頭青龍無足白虎銜尸朱雀悲哭四危已備法應滅族果如其言穀水又東逕函谷闗南東北流皂澗水注之水出新安縣東南流逕毌丘興盛墓東又南逕函谷闗西闗髙嶮峽路出㕓郭漢元鼎三年樓船将軍楊僕數有大功恥居闗外請以家僮七百人築塞徙闗於新安即此處也昔郭丹西入闗感慨於其下曰不乗駟馬高車終不出此闗也去家十二年果如志焉皂澗水又東流入於穀穀水又東北逕函谷闗城東右合桑爽之水<一清按山海經桑爽二水不相連屬此是善長誤證>山海經曰白石山西五十里曰穀山其上多穀其下多桑爽水出焉世謂之紵麻澗<一清按此句是善長所増加非山海經原文下百答水句同>北流注於穀其中多碧緑穀水又東澗水注之山海經曰婁涿山西四十里曰白石之山澗水出焉北流注於穀自下通謂澗水為穀水之兼稱焉故尚書曰伊洛瀍澗既入於河而無穀水之目是名亦通稱矣劉澄之云新安有澗水源出縣北又有淵水未知其源余考諸地記並無淵水但淵澗字相似時有字錯為淵也故闞駰地理志曰禹貢之淵水是以知傳寫書誤字繆舛真澄之不思所致耳既無斯水何源之可求乎穀水又東波水注之山海經曰瞻諸山西三十里曰婁涿之山無草木多金玉波水出於其隂世謂之百答水北流注於穀其中多茈石文石穀水又東少水注之山海經曰廆山西三十里曰瞻諸之山其陽多金其隂多文石少水出於其隂控引衆溪積以成川<一清按八字亦是善長所増加>東流注於穀世謂之慈澗也穀水又東俞隨之水注之山海經曰平蓬山西十里曰廆山其陽多㻯琈之玉俞隨之水出於其隂北流注於穀世謂之孝水也潘岳西征賦曰澡孝水以濯纓嘉美名之在兹<一清按五臣注文選曰澡水經注作濟可見唐時官本原是濟字古□齊作□形與喿似故濟澡互異耳>是水在河南城西十餘里故吕忱曰孝水在河南而戴延之言在函谷闗西劉澄之又云出檀山檀山在宜陽縣西在穀水南無南入之理考尋兹説當承縁生述征繆誌耳縁生從戍行旅征途訊訪既非舊土故無所究今川瀾北注澄映泥濘何得言枯涸也皆為疏僻矣
