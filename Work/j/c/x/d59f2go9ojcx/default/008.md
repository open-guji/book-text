## 原跋
雙溪，一代佳公子也，早嵗作詩有聲，每一篇出，輒誦人口，遇得意處，不下古手，此葢天機頴脱、有不可揜者使然也。是嵗秋八月，以詩近百篇寄虎岩趙君。虎岩，詩人也，見之擊節歎賞，以謂天下竒才，而欲版行，一新衆目焉，而属予題於後。或者曰：「乃公之少作，其可乎？」余曰：「不然。昔唐元微之有《代曲江老人百韻》及《清都夜境》等篇；至於元和中，李長吉、髙軒過二公之作，皆年未及冠，今在集中。數百年間，孰能以少壯為辨而少之耶？言詩者不當以區區嵗月計其工拙矣。」嵗次甲寅季冬二十有五日木庵老衲性英題

嘗觀雙溪詩，氣韻髙逺、清新絶俗，道前人之所不道，到前人之所不到，情思飄如馭風騎氣，真仙語也。彼騷奴詩偷安識。所謂神者，每以不多得為恨，今年秋八月，承寄僅百篇於趙虎岩光祖，不敢珍藏祕惜，乃復刋行之以新世欲見而不可得者。此可與奪標掣鯨手道難為餘子言也。王萬慶跋
