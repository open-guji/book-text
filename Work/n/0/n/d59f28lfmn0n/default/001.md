## 卷一

太子中舍人弘文舘斈士虞世南奉勑撰.臣世南言.臣聞遂古之初.結繩而治.軒轅之世.文斈興焉.史官之作.爰自此始.盖所以書事記言.勸善懲惡.文見褒貶.義存䂓[1]戒.歴代之所共遵.百王之所不易.但炎昊之隆.遺文弗紀.唐虞之盛.謨訓存焉.斯寔[2]先代之風烈.帝王之楷範.暨春秋之世.魯史獨全.夫子因而說經.丘明受而傳[3].但勸升黜.歸之王道.亡國復存.乱臣知懼.諒所謂懸諸日月不栞[4]之書.逮梁木既摧.微言已絕.分門競起.疑論並興.公羊殊於榖梁.張夾異於鄒左.共經而為矛楯.同師逾於楚越.自尔以來.多歴年載.品藻筆削.世之人翰墨繁委.盈於竹素.極慮無以測其厓.窮年不能窮其說.燕石周寶.真偽罕分.走[5]越繁結.雅正[6]相舛.且當世所修.咸多隱諱.是以王沈有不實之書.孫盛有遼東之本.斯並全身遠害.遂使道為時所屈.又有跡見公文.情栛私議.史遷之述[7]漢武.多說妖巫.鄧粲之紀晉元.盛稱家業.陳壽憾於蜀相.沈約讎於宋后.故知良史之難.古今所歎.折衷平允.未易其才.伏惟陛下稽古則天.膺圖撫運.武功文德.遠肅邇安.猶且未明求衣[8].日興思治.屬想大同.凝懷至道.欣南風之在詠.庶東戶之可追.以萬機餘暇.留心墳典[9].鑒往代之興亡.覽前修之得失.乃命有司.刪正四部.研考綈素.綱羅遺逸.翰林冊府.大備於茲.以為乙部之書.其數不少.前後傳記.可相沿襲.殊途同歸.分流共貫.孟堅因數長[10]之書.范曄用華嶠之草.虞預王隱.既曰同文.謝沈山松.曾無二說.溝洫擬於河渠.恩澤生於佞幸.名異實同.其例非一.亦有弗尊舊體.務存新製.標益士之殊稱.騁□者之奇名.載記始於鄧珍.雜録聞於何盛.眩目驚心.誇時動俗.變革徒繁.於義無取.今宜翦截浮辭[11].刪削冗長.畧存簡要.隨而論之.爰命微臣.披文具草.又以眾史為論.皆一往之談.析理研機.或有未盡.可設為賓主.用相啓發.臣謹操觚翰.稟承制旨.但耄及神昬.聽受多昧.才疏學淺.綴輯不工.徒煩簡牘.懼無足采.繕寫始訖.謹以奏聞.謹言.有齊國公子.敏而好學.受業於鄒魯之間.歴覽群書.而凝滯滋甚.乃投卷而難曰.多歧亡羊.古人所戒.博而寡要.亦何為哉.聞有知微先生.在乎上國.將往問焉.於是擔簦負笈.造先生之門.躡履垂纓.膝行請見.先生拂席憑几.匡坐而迎之曰.吾子儼然不遠千里.將何以教之.公子曰.僕東國之鄙人也.以躬耕之暇.竊覽篇籍.歴觀古今治乱之主.或年世長遠.或危亡誅滅.興喪之理.為何所由.豈天意乎.其[12]人事乎.願釋所疑.以祛未寤.先生曰.大哉此之問也.請陳其要.而吾子自擇焉.原夫人之生也.含靈稟氣.異乎草木.有剛柔之性.喜慍之情.愛惡相攻.是非生矣.群而無主.能無乱乎.乃樹立君長.為之司牧.為善則天降之福.禎祥至焉.為惡則天報之禍.妖孽生焉.猶響之應聲.影之[13]隨刑.此必然之理也.所謂禎祥者.非止黃龍丹鳳.甘露醴泉.如周[14]獲磻磎之兆.殷感傅巖之夢.是其祥也.所謂妖孽者.非必[15]鬼[16]哭山鳴.日闘星霣.如周之褒姒.晉[17]之孫強[18].是其孽也.由是觀之.[19]天意人事.相參而成.[20]將為子說治乱之跡.賢愚二貫.若夫三[21]皇五帝之君.德合天地.明並日月.窮機體睿.微妙玄通.固非[22]凡庸所敢輕議.但略陳其事.存而不論.暨乎三代.則主有昬明.[23]世有治乱.興亡之運.可得而言.其明者可為軌範.昬者足為[24]鑒戒.以某狂瞽.試論之.至於守文承平.無咎無譽.非之[25]所由者.亦所不談也.

太皞帝 炎帝 黃帝[26] 少昊 顓頊 帝嚳 唐堯 虞舜[27] 夏禹 太康 少康 桀 殷[28]湯 太戊[29] 武丁 紂 周文王[30] 武王[31] 成王 厲王 宣王 幽王 厲王 平王 秦始皇[32] 二世[33]

略曰.太皞帝庖犧氏.姓風.虵身人首.有聖德.始作瑟卅五絃.制嫁娶之禮.□啚有景龍之瑞.故以龍紀官.故曰龍師.仰則觀象於天.俯則觀法於地.始作八卦以通神明之德.結繩為治.為綱罟以田以漁.取犠牲以充庖廚.故号曰庖犧氏.或号伏犠.

略曰[34]炎帝神農氏.姓姜.人身牛首.始作五弦之瑟.斳木為耜.楺木為耒耨.始教天下種䅽.故号神農.嘉禾生.醴泉出.以日中為市.灾易而退.各得其所.始重八卦為六十四焉.

略曰.黃帝軒轅氏.有熊國君少典之子.姓公孫.始垂衣裳.造書契.置史官.為舟艥以濟不通.服牛乘馬.始立棟宇.重門擊柝.以待暴客.為杵臼以利万民.作弧矢以威天下.諸侯有不服者.從而征之.凡五十二戰而天下大服.有草生於庭.侫人入則指之.名曰屈軼之草.鳳皇巢於阿閣.麒麟遊於囿[35].始作律管.興封禪之礼.子青陽立.是為少昊帝.[36]

略曰[37].帝少昊名摯.字青陽.号金天氏.有鳳鳥之瑞.故以鳥名官.於是修其方.天下大治.[38]

略曰.[39]帝顓頊高陽氏.黃帝之孫.昌意之子.姓姬.平九黎之乱.民神不雜.方[40]物有序.[41]

略曰.帝[42]高辛氏.名夋.姓姬.平共工之乱.制鞞皷鍾磬堹箎.鳳皇皷翼而儛.[43]

略曰.帝堯陶唐氏.名放勛.黃帝之孫.姓祁.聡明文思.允恭克讓.以尹喜為師.許由為友.堂高三尺.茅茨不剪.土階三寸.夏日葛衣.冬日庶裘.有草生於階.以月初一日生一莢.至卅日.日落一莢.若月小則一莢而不落.名曰蓂莢.堯觀之以知旬朔.又生脯於廚.其形如篋.名曰篋脯.暑夏之日廚內常涼.於時景星見.甘露降.醴泉出.朱草生.鳳皇止遊.故仲尼云.唯天為大.唯堯則之.蕩蕩乎.民無能名焉.巍巍乎.其有成功者也.乃舉舜而禪天下焉.崩年百一十八歲.

略曰.帝舜有虞氏.高陽之後.姓媯.瞽瞍之子.父頑母囂弟傲.舜少而至孝.堯聞其聡明.用之.舜乃舉禹為司空.以治水土.棄為后稷.以播百䅽.卨[44]為司徒.以教万民.皋陶[45]為土師.以理獄訟.垂為共工.以典工巧.益為朕虞.以育草木.伯夷為秩宗.以典三礼.戞[46]為樂正.以和神人.百僚咸得其才.堯乃禪以天下.天下太平乃作哥曰.元首明哉.股肱良哉.庶事康哉.又哥曰.元首藂脞哉.股肱惰哉.万事墮哉.於時日月光華.卿雲藂聚.彈五弦之琴.咏南風之詩.曰.南風之薰兮.可以解吾民之慍兮.南風之時兮.可以阜吾民之財兮.作簫韶之樂.鳳皇來儀.擊石撫石.百獸率儛.故仲尼曰.韶盡美矣.又盡善也.以位禪禹.年百歲崩.[47]

略曰.伯禹夏后氏.姓姒.名文命.高陽之孫.父鯀.治洪水九年.其功不成.堯放之於羽山.舜乃舉禹治水.不貴尺璧而重寸陰.櫛風沐雨.冠桂不頋.履脫不納.其人可觀.其言可信.聲為律.身為度.一沐三握髮.一食而三起.陸行載車.水行載舟.泥行乘毳龍.山行乘轎.[48]治水十三年.三過其門.聞兒泣聲而不入也.於是鑿龍門.闢伊闕.導九河.所存者七百國.河出啚.年百歲崩.子啓立.崩.子太康立.[49]

公子曰.夏禹之德.何以不逮於堯舜.

先生曰.昔者三五雖為而不宰.玄功潛運.莫得為名而.是以帝堯之時.有老人擊壤於路曰.吾日出而作.日入而息.鑿井而飲.耕田而食.帝何力於我哉.由此言之.至聖德無跡可尋.故曰.至人無己.神人無功.聖人無名.是以百姓日用而不知也.三代德衰.功用始顯.聞夫夏后之世.敷九土.乘四載.建万國.定九州.栞木導川.其懃至矣.故左傳云.微禹之功.吾其魚乎.帝王之功.莫此為盛.

略曰.帝太康好田獵.田於有洛之表.十旬不及.厥弟五人.御其母以從五子.感怨乃作歌曰.內作色荒.外作禽荒.甘酒嗜音.峻宇雕牆.有一於此.未或弗亡.於是有窮之君曰.羿因民弗忍.距之於河.太康為羿所距.失位而崩.生帝相.相為羿所滅.羿又為其臣寒浞所滅.相有遺腹子曰少康.[50]

公子曰.天子有爭臣七人.雖無道不失其天下.太康有五弟.如此竭忠盡智.以輔其君.上可以追堯舜之跡.下可以安國尊主.而無益於危亡.何也.

先生曰.何代無賢.用与不用.屈原非不智也.見放於楚.子胥非不忠也.流尸於吳.使二主能用兩賢.則楚為七國之雄.吳作九州之伯矣.豈有入閞發憤涌東長歎者乎.人主若能觀五子之誦以為鑒戒.欲求危乱.其可得乎.箴規要切.極於此矣.

略曰.少康.帝相之子.母有仍氏女.相之遇害.其妃逃還有仍.生少康.少康長為仍枚正.寒浞聞其賢.使其子澆求之.少康懼逃.奔有虞為之庖正.其後遂滅浞澆.還復禹跡.祀夏配天下失舊初.夏道復興.[51]其後十六世至帝桀.[52]

略曰.帝桀.名履癸.帝發之子也.桀方有力.能申鉤索䥫.嬖妃曰未喜.未喜所言.桀皆從之.為象廓玉牀.琁室瑤臺.金柱三千.肉山脯林.有諫者以為妖言.罪之.湯使人哭之.乃囚湯於夏臺而後釋之.閞龍逢引黃圖以諫.桀曰.子又妖言矣.吾之有民.如天之有日.日可亡乎.日亡吾乃亡也.於是焚黃圖.煞龍逢.兩日闘.五星錯.行鬼呼於國.枉矢流.火神見.立五十二年.為湯所放.[53]

殷略曰.殷湯名履.姓子.卨之後.壬癸之子也.與葛伯為隣.葛伯不祀.湯使問之.答曰.無以供栥盛.湯使眾為之耕[54].童子餉食.葛伯奪其食而煞之.湯乃征葛伯.東征西夷怨.南征北狄怨.日奚獨.後予后.來其蘓.出覩張羅者.呪其納日.從天下者.從地出者.從四方來者.皆入吾納.湯曰.盡之矣.乃除其三面.留其一面.更呪曰.欲左者左.欲右者右.欲南者南.欲北者北.欲高者高.欲下者下.吾取其犯命者耳.諸侯聞之.一時歸湯者卅六國.有白狼銜鈎入於朝.及黃魚黑玉之瑞.以伊尹為相.伐桀放之南巢之山.其後七年大旱.史卜云.當以人禱.湯乃剪髮斷爪.自為犧牲.禱於桑林之社.言未已.而雨大至.方如千里.踐天子位十三年崩.九世至太戊.[55]

公子曰.成湯之德.何者為首.

先生曰.仁人也.

公子曰.何謂仁人.

先生曰.若夫解三面之網.則翔飛被其澤.剪髮為犧牲.則黔首蒙其惠.仁人之利.不亦遠乎.是以易云.君子居其室出其言.善則千里之外應之.况其迩者乎.此之謂矣.

公子曰.殷湯以武平乱.功施天下.不稱其武而語其仁.何也.

先生曰.仲尼云.驥不稱其力而稱其德.夫葛伯不祀.失礼之主.夏桀狂暴.失道之君也.無礼則乱.無道則虐.乱虐之主.害及生民.湯救焚拯溺以安天下.是故東征西怨.此非仁人之效歟.

略曰.太戊.太康之子.有桑䅽生於朝.旦而大拱.太戊懼而循德.三年重驛而至者十六國.四世至祖乙.以巫咸為佐.殷道復興.六世至盤庚.始改殷曰商.能循湯政.殷道復興.三世至武丁.[56]

略曰.武丁.小乙之子.有雉升鼎.升而雊.武丁懼而恐.道.夢天賜賢人.使百工求之於傅巖之野.乃得悅登以為相.殷道復興.後七世至帝紂.

公子曰.伊尹相成湯於前.傅悅佐武丁於後.二人功業孰者為優.

先生曰.文王卜而遇太公.武丁夢而求傅悅.若非命世太賢.德㕘辰象.豈能感斯冥契.懼自草萊.但遭遇異時.故功業不同耳.觀說命之書.勸戒忠篤.規摹弘遠.實王佐之奇才.師遠之明德.若使与伊尹同時.共仕湯世.則必居佐相之任.賛升陑之業矣.

略曰.紂名辛.大名受.智足以拒諫.辯足以識非.手搏猛獸.撫梁易柱.曳九牛以行.或於但己.造傾宮瓊室鹿臺.餝以美玉.大宮百里.宮中九市.車行酒.騎行炙.以一百廿日為一夜.与崇侯費仲戲於離宮.為酒池糟丘肉林.男女躶而相逐其間.繩羈人頭.□[57]詣酒池.一皷而牛飲者.三千餘人.酔而溺死.時与妲己咲以為樂.以人食獸作熱斗.使執之輙爤手.又為銅柱以膏塗之.加於然炭之上.命人緣焉.墜而燒死.名為炮格之刑.又鹽鬼侯脯刑.侯比干進諫.遂刳其心.又剖婦人腹而觀其胎.斬朝涉者脛而視其髄.六月雨雪.又雨血.又雨名.雨日見鬼哭山鳴.即位卅二年.周武王代而煞之.

公子曰.視桀紂二主.亦同稟五常之性.並有過人之才.何為昏乱以至於此.

先生曰.人有嗜慾之性.愚智所聞也.耳悅鏗鏘之音.目翫靡曼之色.口甘滋腴之味.身安逸樂之娛.此物之常情也.是故聖人制礼作樂以防之.設師保以訓之.使人以名教自節.而趍仁義之道.唯上聖生知.非因習染.自中智以降.皆為情之所引.彼二人者.非布衣草創之君.撥乱匡時之主.皆以承平繼業.漸漬膏腴.外無師傅之嚴.內闕自然之質.不知稼穡之艱難.罔識前代之成敗.及身居南面.血氣方剛.富有區中.制御万物.威若雷霆.勢逾風火.恕則伏戶百萬.喜則賞踰千室.加以絲竹管弦乱其聽.粉黛羅綺或其情.馳騁戈獦快其心.阿諛諂媚從其欲.偃息於九重之內.沉湎於酒色之間.當此之時.自以為与天地而永久.齊日月而為量.豈龍逢比干以區區之志所能諫止者哉.其聞堯舜之土階茅茨.禹湯之愛人罪己.孜孜然以百姓為心者.則大而咲之矣.安得不絕亡者哉.

周略曰.周文王名昌.姓姬.其先出自帝嚳.帝嚳生棄焉.是為后稷.父曰王季.文王出田.卜得賢人.遇呂望於渭濱.因以為相.紂用崇侯之讒.乃囚文王於牗里.作周易彖象.為囚七年.諸侯皆從之囚.紂懼而釋之.出行有枯骨.命吏葬之.吏曰.此無主矣.文王曰.吾即其主也.叄分天下而有其二.猶率殷之畔國以事紂.五星聚房.赤雀銜書.止於王屋.有虞芮二國.爭田入於周境.見周人耕者讓畔.行者讓路.於是慙愧而退.遂為閑田.百姓聞之.一時歸周卅餘國.年九十七而崩.子武王立.[58]

公子曰.文王率殷之叛國以事紂.是助紂為虐.使紂得志天下.流毒百姓.文王之為也.何不仁之甚乎.孰若直辤正諫以匡其惡.

先生曰.夫機者動之微也.非聖人弗能見也.於時歷數雖改.殷眾尚強.紂剛猛暴虐.飾非距諫.豈文王所能動乎.及文王既歿.武王為主.周公佐之.太公為將.猶且還師孟津.曰.紂未可伐.故聖人見機而作.動必万全.不疑滯於物以失機也.於時紂惡未稔.三人尚存.文王屈道事之.盖時宜也.龍虵之蟄.是其義乎.故左傳曰.文王率殷之叛國以事紂.聖知時也.

略曰.武王名發.文王之太子也.以周公旦召公奭為佐.太公望為師.以謀伐殷.遂起師至於鮪水.王韈解.五人御於前.莫肯為王結之.皆曰.臣所以事王.非為結韈也.王乃釋旄俯而自結之.出見暍人停車扇之.度河白魚入於舟.伐紂既剋.乃封比干之墓.式商容之閭.釋箕子之囚.歸傾宮之女.散鹿臺之錢.放馬華山之陽.休牛桃林之塞.倒載千戈.示不復用.年九十三而崩.太子立是為成王.

公子曰.文王盛三分之業.屈道以事殷.武王率八百之師.稱兵而滅紂.豈德有優劣.物運窮通.何其二聖殊塗.如斯之遠.若牖里為是.則牧野為非.謂剪商為工.則事殷為屈.願聞篤論.以釋所疑.

先生曰.夫四時平分.冬夏有暄寒之辯.五常遞運.水火有剛柔之殊.至於利物成務.其道同矣.文王夷明晦跡.藏用所以頭[59]仁.武王果毅發揚.龔行所以靜乱.然則濟世庇民.其揆一也.奚必脩文為是.而允武為非乎.期於至公而已矣.

略曰.成王名誦.武王太子也.成王之時.周公為相.政致太平.有鳳皇集於紫庭.王乃作哥曰.鳳兮鳳兮集紫庭.余何德兮以感靈.初周公作相.二弟管叔蔡叔狹紂子武庚作乱.周公誅之.天下乃定.成王崩.太子立.是為康王.[60]

公子曰.昔虞舜之弟曰象.恒以煞舜為事.及舜即位而封之.此亦聖人之教也.周公曷為不赦管蔡之罪而誅放之乎.

先生曰.象之害舜.舜猶為布衣.在田畝之間.此盖一身之禍耳.至如管蔡為乱.則謀危社稷.周公之行戮.豈為身哉.盖以救率土之命而存宗周之祀.大義滅親.斯此之謂.是以春秋云.管蔡為戮.周公右[61]王.夫豈不愛王室故也.

略曰.康王名釗.成王太子也.自成王即位.迄於康王.刑厝不用.後八世至厲王.[62]

略曰.厲王名故.夷王之太子也.厲王無道.國人謗之.王怒使衛巫監.得謗而煞之.百姓莫敢言.道路以目.於是作乱.流王於彘而崩.[63]子宣王立.

略曰.宣王名靖.厲王太子也.召穆公為相.進用賢良.尹吉父.南仲.方叔等.周道中興.王不藉千畝.掃文王諫不聽.又与姜戎戰.敗績於千畝.乃䉼民於太原.仲山甫諫不聽.王政大衰.立卌六年崩.太子立.是為幽王.

公子曰.周宣王之德.其令主乎.

先生曰.宣王為詩人所詠.其詞其[64]美.觀夫人之事跡.殆不充乎雅頌.詳而論之.知其所以然也.何則周室陵夷.其來久矣.重以厲王暴虐.毒流境內.万姓嗷嗷.息肩無所想.逢寬政如農夫之望歲焉.及周宣即位.任用賢能.南服荊舒.北威獫狁.天下翕然.稱為至治.是以四牡翼翼.美征伐之功.鸞聲鏘鏘.歌礼樂之盛.此則疲民易為仁也.其後喪師千畝.䉼民於太原.怨㓨之文於此而作.詩云.靡不有初.鮮克有終.盖謂此也.

略曰.幽王名宮皇.宣王太子也.即位三川震.岐山崩.王伐褒人.褒人以褒姒辝之.王或於褒姒.褒姒讒申后及太子宜臼.王乃廢申后.逐太子.又伐申侯.申与犬戎伐周.煞幽王.初幽王与諸侯約有寇則擊皷舉烽火.諸侯來赴.及或於褒姒.姒不好咲.王欲其咲.乃擊皷舉烽.諸侯皆至而無寇.褒姒乃大咲.又好聞裂繒之聲.王為發繒裂之.以適順其意.及申侯与犬戎兵至.王擊皷舉烽.諸侯以為如前見欺.無復至者.故遂敗滅.太子立.是為平王.

公子曰.幽厲二王.暴虐無道.觀其行事.足亡社稷.而宗廟猶存.國不遂滅.何也.

先生曰.夫源深者其流必長.德厚者其祚必遠.周自后稷已來.積仁累聖.澤及行葦.同姓兄弟.犬牙相制.內有凡名[65]群公.外有晉鄭諸國.侯伯遞起.惣其盟會.宣力竭忠.同將王室.此其所以不遂亡也.

略曰.平王名宜咎.幽王太子也.避犬戎之難.東遷洛陽.周室遂弱.後廿二世至赦王.為秦所滅.

公子曰.平王䠞弱東遷.捐棄豐鄗.与夫布綱治紀.不亦乖乎.

先生曰.昔紀季以酅入於齊.以存本國之祀.春秋善之.平王自徙國已來廿餘世.子孫勿替.將三百年.此与大王居歧山其義一也.度德量力.何所譏焉.

秦略曰.秦始皇名政.莊襄王之太子也.秦氏始自非子.封於秦.其後稍大.至惠文王始稱王.五世至始皇.以李斯為相.蒙恬王剪為將.攻六國自号帝.焚書坑儒.偶語者死.棄灰於道者刑.北築長城.南戍五嶺.收太半之賦.作叅夷之刑.又使徐福入海.求蓬萊山.天下怨毒.長子扶蘓諫.始皇怒乃使扶蘓監蒙恬築長城於上郡.有星墮於地.則為石.民刻其石曰.始皇死而地分.始皇恕[66].俱誅石傍家.焚其石.卅七年始皇東巡海上.少子胡亥.丞相李斯及車府令趙高從.至沙丘而崩.趙高与李斯作為[67].始皇遺詔.賜太子扶藉死.立少子胡亥.是為二世皇帝.

略曰.二世立.趙高潛煞李斯.以高為丞相.尃任刑誅.用法益酷.於是陳勝等.起六國各自立為王.項羽率諸侯伐秦.二世數以盜賊事責趙高.高懼.乃煞二世.二世立三年而死.立二世兄子子嬰.項羽至煞子嬰.秦祚遂滅.

公子曰.秦始皇起秦隴之地.蠶食列國.遂滅二周而遷九鼎.併吞天下.平壹宇內.其規摹功業.亦已大矣.何為一身幾殞.至子而亡乎.

先生曰.彼始皇者.棄仁義而用威力.此可以吞併而不可以守成.貽訓子孫.貪暴而已.胡亥才不如秦政.趙高智不及李斯.以暗主而御姧臣.遵始皇貪暴之跡.三載而亡.已為晚矣.[68]
