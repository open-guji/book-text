## 卷二[69]

漢[70]高祖[71] 太宗文皇帝 世宗景皇帝 世祖武皇帝 孝昭皇帝 海昏侯 高祖孝宣皇帝 孝元皇帝 孝成皇帝 孝哀皇帝 偽新王莽[72] 後漢世祖光武皇帝[73] 顯宗孝明皇帝 肅宗孝章皇帝 孝桓皇帝 孝靈皇帝

略曰.漢高祖名邦.字季.沛豐人也.父太公名執嘉.母媼甞息大澤之陂.夢与神遇.時雷電晦暝.大公往視.交龍於其上.已而有娠.高祖隆准而龍顏.有大度.寬仁愛人.意豁如也.有呂公者善相.相高祖大貴.以女妻焉.即呂后也.為泗水亭長.常酔.夜經澤中.有虵當道.高祖拔劔斬之.後至者見一嫗.哭曰.吾子白帝子化為虵.今赤帝子斬之.始皇常曰.東南有天子氣.東巡以厭之.高祖隱於芒錫山澤間.上常有雲氣.二世元年.起兵於沛.自立為沛公.破秦軍.入咸陽.獲秦王子嬰.初入秦.除秦苛法.約法三章.煞人死.傷人及盜者抵罪.秦民大悅.項羽至鴻門.沛公見羽.羽与沛公飲.範増使項莊入以劔舞.將擊煞沛公.羽季父項伯亦起舞以身蔽沛公.故免.五星聚於東井.項羽立沛公為漢王.漢王乃東伐.定三秦.擊項羽.敗於彭城.太公呂后為羽所得.羽圍熒陽.使謂沛公曰.不急下吾享太公.沛公曰.与羽約為兄弟.吾翁即汝翁.汝欲享.分吾一杯羹.又與羽戰於廣武.羽伏弩射漢王.傷胷.五年至彭城.誅項羽.立為皇帝.帝在洛陽南宮見諸將.往往偶語.問張良.良曰.反.帝曰.為之奈何.良曰.帝所不快.群臣所共知者誰.帝曰.雍齒數窘辱我.乃先封雍齒為侯.群臣乃喜.曰.雍齒且侯.吾屬無患.帝置酒謂群臣曰.通侯諸將.無敢隱朕.吾所以有天下者.何項氏所以失天下者.何高起.王陵對曰.階下使攻城略地.因以与之.与天下也.同利所以得天下.項羽戰勝而不與人功.得地而不與人利.此以失天下也.上曰.公知其一.未知其二.夫運策於帷帳之中.决勝於千里之外.吾不如子房也.鎮國家撫百姓.給餉餽不絕粮道.吾不如蕭何.連百萬之軍.戰必勝.攻必取.吾不如韓信.三者皆人桀.吾能用之.此吾所以取天下也.項羽有一範増而不能用.此其所以為我所禽也.初都洛陽.用婁敬之計.西都長安.北伐凶奴.婁敬諫不聽.為凶奴所圍.用陳平秘計得出.即赦婁敬.謝之曰.不用公言以至於此.即位十二年崩.年六十二.初黥布反.帝自擊布.為流矢所中.及困.呂后問以後事.曰.蕭相國死.孰可代之.曰.曹參可.問其次.曰.周勃.可安劉氏者.必教也.子惠帝立.

略曰.[74]帝.名盈.呂太后子也.即位七年崩.呂太后立.後宮子為惠帝子.實呂氏子也.又立呂台.呂產.呂祿.皆為王.於是朱虛侯劉章与大臣共誅諸呂.及少帝立.又帝初.高帝寵戚夫人.生趙王如意.帝愛之.欲以代太子.呂后深怨之.呂[75]帝憂萬歲後如意不全.及惠帝立.呂后截戚夫人手足.挑去眼.名曰人彘.煞趙王如意.

公子曰.漢高撥乱反正.為一代英主.可謂盡美盡善者乎.

先生曰.漢高祖起自卑微.提三尺劍以取天下.實有英雄之度量焉.故班氏王命論云.漢高之興有五.一曰帝堯之苗裔.二曰體皂[76]多奇異.三曰神武有微[77]應.四曰寬明而仁恕.五曰知人善任使.加之以信誠好謀.達於禮愛[78].見善如不及.用人如由己.從諫如順流.趍時如響赴.此其所以得天下也.然知呂后之耶僻而不能正.愛趙王如意而不能全.身沒之後.幾亡社稷.若無劉章周勃.呂氏幾代漢矣.此之為過.甚於日月之蝕.豈盡善之謂乎.至於克平秦項.創開漢業.前後卜世積數百年.衣冠礼樂垂之後代.雖未階王道.霸德之盛者也.

略曰.文帝諱恆.薄姬之子.帝性寬仁儉素.甞欲起露臺.石匠計之.直百金.帝曰.百金中民十家之產.吾奉先帝宮室.常恐羞之.何以臺為.有獻千里馬者.帝曰.吾吉[79]行五十里.師行卅里.獨行千里馬.欲何之乎.所幸慎夫人衣不曳地.身衣弋綈集上書裳以為殿.惟除肉刑.及收帑相坐.律令有犯誹謗妖言之罪者.勿治除閞不用.傳張武受金.帝加賞賜以愧其心.專務以德化民.天下斷獄四百.幾致刑厝.初.帝夢升天有一黃頭郎推之.覺而求之.則鄧通也.乃賞通以蜀銅山.得自鑄錢.趙人新垣平使人持玉杯於闕下.因謂帝曰.闕下有寶器.取而獲焉.其後詐覺.夷平三族.即位廿年.年卌六.子景帝立.

略曰.景帝名啓.文帝太子也.亦務無為.名亞.文帝初.文帝除肉刑.以箠代之.猶多死者.帝立令減其箠.由是死者少焉.然用朝[80]錯之策.侵削諸侯.又甞与吳太子愽局[81]抵.煞吳太子.吳王由此怨恨.遂与七國俱反.又斬朝[82]錯以謝七國.丞相周亞夫平七國有大功.帝心忌之.使有司誣亞夫反.亞夫下獄自煞.帝即位十年.年卌八.子武帝立.

公子曰.班固云.周云成康.漢稱[83]文景.斯言當乎.

先生曰.成康承文武遺跡.以周劭[84]為相.化篤厚之氓.因積仁[85]德.疾風偃草.未足為喻.至如漢祖開基.日不暇給.亡嬴之弊.猶有存者.鑿㒹抽脅.尚行於世.[86]太宗[87]體茲仁恕.式遵玄默.滌秦項之酷烈.反軒昊之淳風.幾致刑厝.斯為難矣.若使不溺新垣之說.無取鄧通之夢.懍懍乎庶幾近於王道.景帝之擬周康.則尚有慙德.

略曰.武帝名傲.景帝太子也.既立.改号建元.罷黜百家.建興庠序.進用賢良.公孫弘.兒[88]寬等.以衛青.霍去病為將.北伐凶奴.開河南.朔方地.又南平百越.東滅朝鮮.以為郡縣.封太山禪.梁甫山稱万歲.神光並興.獲麒麟朱鷹.既連年征討.又盛脩宮觀.天下虛耗.國用不足.乃以八月酎酒祭宗廟.令諸侯出金以助祭.号曰酎金.其色惡及不中稱兩.皆奪一爵.丞相趙周又以水銀着稱衡中.令金色變.於是諸侯坐酎金.失國者甚眾.又禁百姓治酒及賣鹽䥫.唯官得賣之.又令諸侯來朝.以白鹿皮廌珪.名曰皮幣.唯禁菀有白鹿.因賣其皮与諸侯.一枚直卌金.又金民出緍錢.六畜舟車.皆出租稅.末年好神仙.以公主妻術士.又信巫蠱之言.太子公主丞相皆坐誅.皇后自煞.其百姓大臣坐死者數万.貪汗血之馬.則万里伐宛.甞蒟醬之味.則西開西南夷.其不愛民命以從己欲.如此.後元年二年崩.即位五十四年.年七十一.子昭帝立.

公子曰.觀[89]漢武帝雄才大略.可方前代何主.

先生曰.漢武承六世之業.海內殷富.又有高人之資.故能惣覽英雄.駕御豪桀.內興礼樂.外開邊境.北懾匈奴.南平百越.若其開學校.盛文詞.[90]制度憲章.煥焉可述.方於始皇.則為優矣.至於驕奢暴虐.可以相亞.並功有餘而德不足.

略曰.昭帝名弗.武帝少子.即位年十四.改元為始元元年.大將軍霍光及左將軍上官桀執政.桀害光寵.欲誅之.乃詐為帝兄燕王旦上書.稱光行上林稱蹕.又私調校尉.桀乃奏燕王表.霍光□□開之.不敢入.帝名之曰.大將軍無罪.朕知此書詐也.光曰.陛下何以得知之.帝曰.大將軍上林近耳.調校尉來.未能十日.燕王何以得知之.且將軍為非不須校尉.帝知將軍欲反.不由一校尉.由是光得盡忠.上官桀詐偽.事發伏誅.泰山大石.自立上林.枯柳之生.有鳳皇集.改元鳳元年.即位十三年崩.年廿二.武帝孫昌邑王賀立.

公子曰.漢昭帝周成王俱以劭[91]年並有令聞.孰者為賢.

先生曰.二人之德.前代已有論矣.

公子曰.願聞斯論.

先生曰.論者以為周成王者.武王之子.文王之孫.周公之兄子也.有累世聖人之資.其聰睿不足恠也.至如昭帝.父非武王.祖非文王.叔非周旦.而卓然不群.夙智如此.且成王疑周公以流言.昭帝明霍光之無罪.此之優劣.相去遠矣.

略曰.昌邑王賀.昌邑哀髆之子.初奔喪稱嗌痛.不肯哭.在道以車載女子.行至濟陰.求長鳴雞精竹林.及即位媱乱賜侍中君卿.黃金千斤以取十妻.昭帝喪在前殿.賀引內樂人皷吹歌舞.駈□北宮.弄彘闘獸.与昭帝宮人乱.与官奴夜飲.在位凡廿七日.有事凡一百廿七條.侍中縛嘉諫.縛嘉繫獄.於是霍光廢賀為海昬侯.立武帝玄孫詞.是為宣帝.

公子曰.漢之昌邑.淫昬已甚.比之桀紂.可為疋乎.

先生曰.桀紂之王.各已十載.負扆南面.歷年永久.然後惡被生昬.害加百姓.昌邑蕃國之嗣.擢居元首.朽索馭奔.猶懼不剋.况乃身服苴斬.梓宮在殯.形尊御極.曾未三旬.沉湎昬縱如斯之甚.若使遂享中國.肆其狂暴.則夏癸商辛未足比也.

略曰.宣帝名詢.武帝曾孫.衛太子之孫也.足下生毛.臥居如有光矅.即位改号為本始元年.好法律.留心治道.進用良吏.並皆稱職.常稱曰.使百姓無愁恨之氣者.實唯良二千石.每幸宣室.齋居而决事.由是百司稱其能.鸞鳳神雀甘露降集.頻年豐稔.䅽石五錢.呼韓耶單於[92]入侍.号稱中興帝.即位廿五年.年卌二生元帝.

公子曰.漢宣帝政甚[93]明察.其光武之儔歟.

先生曰.漢宣起自閭閻.知民[94]疾苦.是以留心以[95]政.擢用賢良.源[96]其循名責實.峻法嚴令.盖流出於申韓也.元帝為太子.嘗諫帝.以為持法太嚴.帝作色曰.我漢家以霸王之道雜之.奈何純任德化.用害政乎.由此觀之.知其度量不遠矣.[97]古語云.啚王不成.弊猶足霸.啚霸不成.弊[98]如何.光武仁義.啚王之君也.宣帝刑名.啚霸之主也.今以相軰.恐非其倫.

略曰.元帝名奭.宣帝太子.帝柔仁好儒.見宣帝所用多文[99]法吏.以刑名繩天下.大臣陽渾.盖寬饒等坐譏㓨而誅.縱容諫帝.帝歎曰.乱我家者太子也.宣帝崩即位.改号□□□□[100].罷黃門.柔輿狗馬.水衡禁菀.假与貧民.賜前將軍蕭望之…中書令弘恭.石顯.潛望之.令自…[101]

或曰.漢元帝才藝溫雅.其守文之良主乎.

虞南曰.夫人君之才.存乎遠大之略.[102]在乎文德武功而已.文則經天緯地.詞令典策.武則禁暴戢兵.安人和眾.此南面之宏圖也.至於鼓瑟吹簫.和聲度曲.斯乃伶官之職.豈天子之所務乎.[103]

公子曰.成帝委任外民.卒危劉宗.哀帝寵幸董賢.將禪天下.二失孰大.

先生曰.其乱亡之舋.一也.成帝任用王氏.猶經歷三世.陵夷已漸.哀帝耽惑董賢.乃欲身禪帝位.其為昬僻.乃速於成帝矣.[104]

或曰.觀偽新[105]王莽.克己修身.[106]謙恭禮讓.豈非一代之名士乎.至[107]作相居尊.驕淫暴虐.何先後相背若斯之甚.[108]

虞南曰.王莽[109]天資慘酷.詐偽人也.未達之前.徇名求譽.得志之後.矜能傲物.飭情既盡.而本質存焉.[110]愎諫自高.卒不改寤.海內冤酷.為光武之驅除焉.[111]

或曰.夏少康漢光武.皆中興之君.孰者為最.

虞南曰.此二帝.皆興復先緒.光啟王業.其名則同.其實則異.何者.光武之世.藉思乱之民.誅殘賊之莽.取乱侮亡.為功差易.至如少康.則夏氏之滅已二代矣.藐然遺體.身在胎孕.母氏逃亡.生於他國.不及過庭之訓.曾無強近之親.遭離乱之難.庇身非所.而能踦驅[112]於喪乱之間.遂成配天之業.中興之君.斯為稱首.[113]

公子曰.光武中興之主.方之漢高.孰為優劣.

先生曰.論者云高祖豁達以大度.光武細密於條目.各擅其美.龍飛鳳舞.故能撥乱庇民.拯斯塗炭.[114]帝者與師處.王者與友處.霸者與臣處.漢祖之臣.三傑是也.光武之佐.二十八將是也.豈得以鄧禹吳漢匹於張良韓信者乎.然漢祖功臣.皆以強盛誅滅.光武佐命.悉用優秩安全.君臣之際.良可稱也.絕長補短.抑其次焉.

公子曰.明章二帝.比於前漢.可方何主也.

先生曰.明帝政治明察.可比孝宣.而度量弗及也.章帝仁恕恭儉.有太宗之風.二帝之方文景.可謂具體而微矣.並一代明主.魏晉已來.咸莫之逮.[115]

或曰.後漢衰乱.由於桓靈.二主凶德.誰則為甚.

虞南曰.夫岷江初發.其源可以濫觴.及其遠也.方舟而後能濟.元帝之時.而任弘恭石顯.暨於桓靈.加以單超張讓.既斁彝倫.遂傾宗國.其所由來者漸矣.故曰.熒熒不滅.炎炎奈何.言慎其始也.嗚呼.百代之後.其鑒之哉.[116]桓帝赫然奮怒.誅滅梁冀.有剛斷之節焉.然閹人擅命.黨錮事起.[117]中平乱階.始於桓帝.古語曰.天下嗷嗷.新主之資也.靈帝承疲民之後.易為善政.黎庶傾耳.咸冀中興.而帝襲彼覆車.毒逾前輩.[118]傾覆宗社.職帝之由.天年厭世.為幸多矣.
