## 卷三

三國君主 晉宣帝與諸葛亮 晉景帝與晉文帝 晉武帝晉惠帝 晉元帝 謝安 晉明帝 晉孝武帝 桓玄

或曰.自炎精不竸.㝢縣分崩.曹孟德挾天子而令諸侯.劉玄德憑蜀漢之阻.孫仲謀負江淮之固.三分天下.鼎足而立.皆肇開王業.光啟霸圖.三方之君.孰有優劣.

虞南曰.曹公兵機智算.殆難與敵.故能肇迹開基.居中作相.實有英雄之才矣.然譎詭不常.雄猜多忌.至於殺伏后.鴆荀彧.誅孔融.戮崔琰.婁生斃於一言.桓邵勞於下拜.棄德任刑.其虐已甚.坐論西伯.實非其人.許劭所謂治世之能臣.乱世之姧雄.斯言為當.劉公待劉璋以賓禮.委諸葛而不疑.人君之德.於斯為美.彼孔明者.命世之奇才.伊呂之儔匹.臣主同心.魚水為譬.但以國小兵弱.斗絕一隅.支對二方.抗衡上國.若使與曹公易地而處.騁其長算.肆關張之武.盡諸葛之文.則霸王之業成矣.孫主因厥兄之資.用前朝之佐.介以天險.僅得自存.比於二人.理弗能逮.

公子曰.諸葛亮冠代奇才.志圖中夏.非宣帝之雄謀妙算.其孰能當斯勍敵者乎.[119]

先生曰.宣帝起自書生.叅贊[120]帝業.濟時[121]定難.克清王道.文武之略.實有可稱.然[122]多仗陰謀.不[123]由仁義.猜忍詭狀.盈諸襟抱.至如示謬言於李勝.委鞠獄於何晏.愧心負理.豈君子之所為[124].以此偽情.行之萬物.若使力均勢敵.俱會中原.以仲達之姧[125]謀.當孔明之節制.恐非儔也.[126]

公子曰.晉景文兄弟.遞居宰相.二人功德.孰為先後.[127]

先生曰.景帝少有名節.見重當時.所以何平叔云.惟深也故能通天下之志.夏侯玄[128]是也.惟幾也故能成天下之務.司馬子元是也.故知王佐之才著於往日.及誅爽之際.智略已宣.欽儉稱兵.全軍獨克.此足以見其英圖矣.雖道盛三分.而終身北面.威名震主.而臣節不虧.侯服歸全.於斯為美.太祖嗣興.克寧禍乱.南定淮海.西平庸蜀.役不逾時.厥功為重.及高貴纂位.聰明夙智.朝野欣欣.方之文武.不能竭忠葉贊.擬跡伊周.遂乃偽殺彥士[129].委罪成濟.自逆貽節.終享惡名.斯言之玷.不可為也.[130]

公子曰.武帝克平江表.混一宇內.可謂晉之明主乎.

先生曰.武帝平一天下.非曰不然.至於創業垂統.其道則闕矣.夫帝王者.必立德立功.可大可久.經之以仁義.緯之以文武.深根固蒂.貽厥子孫.一言一行.以為軌範.垂之萬代.為不可易.武帝平吳之後.怠於政事.蔽惑邪佞.留心內寵.用馮統之讒言.拒和嶠之正諫.智士永歎.有識寒心.以此國風.傳之庸子.遂使墳土未幹.四海鼎沸.衣冠殄滅.縣宇星分.何曾之言.於是信矣.其去明主.不亦遠乎.[131]

公子曰.晉惠之時.張華.裴頠盡忠王室.扶顛救危.猶足南面.何以坐視其弊危而不救焉.

先生曰.晉自太康之末.風教淩遲.俗澆薄為日久矣.况惠帝稟質下愚.賈后天性兇狡.以兇狡之性役下愚之質.猶縱烈火而潦於原野.自楊駿滅後.誅戮相繼.八王力爭.戎狄窺覦.頹綱漏網.一時崩潰.非命代英雄不能正也.張.裴儒雅.安足用之.[132]

公子曰.中宗值天下崩離.創立江左.俱為中興之主.比於前代.功德云何.

先生曰.元帝自居藩邸.少有令聞.及建策南渡.興亡繼絕.委任宏茂.撫綏新舊.故能嗣晉配天.良有以也.然仁恕為懷.剛毅情少.是以王敦縱暴.幾危社稷.蹙國舒禍.其周平之匹乎.[133]

公子曰.東晉自元帝以下.何為賢主.[134]

先生曰.晉自遷都江左.強臣擅命.垂拱南面.政非已出.王敦以磐石之宗.居上流之勢[135].負才矜地.志懷問鼎.非明帝[136]之雄斷.王導之忠誠.則晉祚其移於他族[137]矣.若使降年永久.佐[138]任群賢.因瀍澗之遺黎.乘劉石之衰運.興復中原.[139]不難圖也.[140]

公子曰.謝安[141]為相.可與何人為比.

先生曰.昔顧雍封侯之日.而家人不知.故前代稱其賢乎.夫以東晉衰微.江左凋弊.戎狄交侵.疆場日駭.况永固苻堅英主.親率百萬.苻融名將.執銳前驅.厲竇衡之觜距.騁張蚝之鋒鍔.先築賓舘.以待晉居.強弱而論.雖鴻毛大山不足為喻.文靜深拒桓冲之援.不喜謝玄之書.則勝敗之數.固以在於胸中矣.斯人也.豈以區區萬戶之封動其方寸矣.若論其度量.近古已來.未見共匹.惜哉.不與八元.三傑齊衡接殄.驤首太階.贊升平之葉矣.[142]

公子曰.中興之政.咸歸大臣.惟孝武為君.威福自己.外摧強寇.人安吏肅.比於明帝.功業如何.

先生曰.孝武克夷外難.乃謝安之力也.非人主之功.至於委任會稽.棟樑已撓.殷王作鎮.乱階斯起.昌明之讖.乃驗於茲.加以末年沉晏.卒致傾覆.比蹤前哲.其何遠乎.[143]

公子曰.桓玄聰明有夙智.英才遠略.亦一代之異人.而遂致滅亡.運祚不終.何也.[144]

先生曰.夫人君之量.必器度宏遠.[145]虛己應物.覆載同於天地.信誓合[146]於寒暄[147].然後萬姓樂推而不厭也.彼桓玄者.盖有浮狡之小智.而無含宏[148]之大德.值晉室[149]衰乱.威不迨下.故能肆其爪牙.一時篡奪.安國治人.無聞焉爾.以僥倖之才.逢神武之運.[150]至於夷滅.固其宜也.[151]
