闕朝賀仍

康熈五十一年九月二十日理藩院
題為内五十旗王以下台吉他布囊以上來朝等事十月初六日大學士<臣>溫達等啟奏摺本奉
㫖元旦來朝蒙古諸王内或公事差遣或正務羈絆以及有病不可行動之外左右兩翼王貝勒貝子公台吉他布囊等一槩聽其前來爾等㑹同理藩院議奏欽此欽遵大學士<臣>溫達等㑹同理藩院議得左右兩翼王以下協理旗務台吉他布囊以上
一槩聽其前來伊等來時其扎薩克台吉他布囊俱留一人令其䕶理印務不可荒廢地方再公主之子孫俱係親戚台吉等内有年歳大者亦令其前來其不能來之王貝勒貝子公扎薩克台吉他布囊每一旗令其來一台吉他布囊如有公事差遣正務羈絆有病不可行動者竝年未及歳者俱不必令其前來又查從前元旦來朝人内未經出痘者不令前來今或令其前來或不必令其前來伏候

㫖依議其未出過痘之人不必令其前來欽此欽遵康熈五十二年王以下台吉他布囊以上赴
