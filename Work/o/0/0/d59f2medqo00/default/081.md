<臣>聞之大雅嘉樂之詩曰嘉樂君子顯顯令德宜民宜人受祿於天保佑命之自天申之言聖人受天之祿而天命之申重保佑無有巳時蓋皆由其宜民宜人令德所致也而既醉之詩其稱君子萬年者葢長言不足而咏歌之至於反復數四而不厭其言之重詞之複焉<臣>以是知聖人在上躬大德而受天命於以長享景福至於億萬斯年非天之獨私獨厚於聖人其夀一人者亦所以福天下也則夫四海之内凡厥庶民朝廷之上百辟卿士所由作為歌詩用申其□於天子之意非徒臣子愛戴君父為分誼當然亦皆自幸其生逢聖世獲事聖君親覩太平躬值盛事而歡欣鼓舞不能已於言也然自生民以来聖人受命而興躬備令德以宜其民人而致天命之申重保佑未有盛於我
