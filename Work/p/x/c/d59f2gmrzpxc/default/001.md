## 和序

醫家惟小兒科爲尤難。蓋自其能言而被病者，猶可以問而知之，而其未能言者，不可以問而知也。《史》言扁鵲入咸陽，爲小兒醫，然鵲之書多不傳其言。有曰∶望而知之謂之神，聞而知之謂之聖，鵲之術固不在於書歟。信斯言也！惟鵲爲可也。夫醫不可以無書也，太倉公乃亦以醫者意耳，不肯爲書，使倉公者常有於世焉，雖無書可也，如倉公之不常有。何哉？且吾聞學醫者與學儒無異。儒者求聖贤之心法，以有聖贤之書存焉耳。醫無其書，則轩岐之心法泯焉而不傳久矣。又何由而學之？故醫書之浩衍，與儒書相埒，殆又过之。然板行於天下，人得而有之者，往往大方脉之書爲多，彼爲小兒者，每以专科自名，或私得一方，即祖父子孙相傳，世享其利，他人万金罔顾授也。其肯與天下后世公共之哉？育溪曾君，用儒攻醫，得戴刘二家之傳，自少至老，凡活人之幼者，枚数不知几何人。在证处方，皆超然众醫之表，乃以得之师傳者，广粹精核，爲活幼心書一编。既成不以私其家，将以公之天下后世，使爲其术者，無學醫废人之患。凡人之幼，皆有成人之望焉，浓哉育溪之用心也，人孰無此心哉？皆能以育溪之心爲心則善矣。雖然，書本陈言，心须活法，或徒泥其書而不善用，譬之兵家，不知合变，胶柱而调瑟焉，吾未见其可也。昔临安李立之者，以小兒科擅名一时。有婴兒忽病喑，求治之，立之令人乘高扑之地下，以一衾盛之，兒不觉大惊，遂发声能言。問之。曰∶此乳搐心也，非药所能疗。此活法之说也，因附着之。

泰定丁卯闰九月朔中议大夫前同知海北海南道宣慰使司事副都元帅和尼赤序
