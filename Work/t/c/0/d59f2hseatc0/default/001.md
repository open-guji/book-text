## 序

吾汶藁序
余舊聞宋太學生廬陵王鼎翁作生
祭文丞相文每嘆曰士生扵世不幸
當國家破亡之時欲為一死而無可
死之地又作為文章以望其友為萬
死立綱常其志亦可悲矣然當是時
文丞相興師勤王非不知天命巳去
天下巳不可為廢數十萬生靈為無
益誠不忍坐視君父之滅亡而不救
其死國之志固巳素定必不待王鼎
翁之文而後死使文丞相不死雖百
王鼎翁末如之何况一生鼎翁耶且
其文見不見不可知而大丈夫從容
就義之意亦有衆人所不能識者近
從其門人劉省吾得王鼎翁集始見
所謂生祭文丞相文既歴陳其可死
之義又反覆古今所以死節之道激
昻奮發累千五百餘言大意在速文
丞相死國使文丞相志不素定一讀
其文稍無苟活之心不即仗鈎必自
經扵溝瀆豈能間關顛沛至扵見執
又坐燕獄數年百計屈之而不可然
後就刑都市使天下之人共覩扵青
天白日之下曰殺宋忠臣文丞相何
其從容就義若此哉故文丞相之死
國必不係王鼎翁之文其文見不見
又不可知而鼎翁之志則甚可悲矣
即王鼎翁居文丞相之地亦豈肯低
首下心含垢忍恥立他人之朝廷乎
鼎翁德之粹學之正才之雄詩文之
奇古則劉㑹孟先生言之備矣兹不
復論獨論文丞相之心與鼎翁之志
云
元統二年春中奉大夫翰林侍講讀
直學士同知經筵事掲傒斯撰
吾汶藁序
論人行事權舉而穪之者其善為可
數論人文章舉一以蔽之者其善為
不可勝數也廬陵王梅邊先生與先
君渤海侯為太學存心齋同舍咸淳
甲戌隨路混補入學又同生淳祐之
壬子先君常穪其才噐卓犖有往哲
風運改世遷篤志稽古蘄為文章以
見志余恨未及一識他日從其門人
劉君省吾得吾汶藁讀之至生祭文
丞相文作而嘆曰嗚呼王鼎翁宇宙
奇士也士之趣人以自裁者惟朱雲
扵其師蕭望之然望之特一身計耳
鼎翁之為言為天下萬世之為人臣
者計也嗚呼雄哉盖嘗論之斯文者
宇宙之元氣也幸而治平措諸事業
則為典謨為雅頌不幸而反是則為
春秋為變風雅為離騷然其正人心
扶世教之功難見于治平無事之時
而屹然可仗扵流離顛沛之日然後
知斯文之所繫如是其重歟詩曰德
輶如毛民鮮克舉之我儀圖之維仲
山甫舉之愛莫助之夫大人維持之
際惟是心耳何其深厚悠長之味溢
岀言表耶文武之澤在人其未冺歟
鼎翁是篇與是詩詞氣雖若不同實
相表裏吾故表而岀之他詩文竒氣
壯節類是也
元統二年春中順大夫僉太常禮儀
事歐陽玄撰
忠義錄序
元嘗讀文山集見載今太史胡文穆
公所撰文丞相傳偹叙其忘身殉國
履歴艱險至于千挫百折而後就義
以死恒窃傷之然猶意其義夫烈士
周旋往來其間亦有史不盡書冺没
而無以自見者正德甲戌蒙恩送母
家居㑹安成王公由南禮曹左遷守
予峽岀吾汶藁讀之乃其族祖梅邊
先生所著也梅邊宋太學生未有民
社之寄文山起兵勤王即應召畫策
尋　辭歸其心必存不安者及
文山再執恐　遲回也
為生祭文以速之既而得死復為文
北望以祭今具載藁中其志亦偉矣
夫顯而易見者事隱而難知者心文
山力圖恢復人莫不知忠義天植要
不必助于人生祭之作其見與否不
可知而梅邊孤忠勁節悲壮激烈之
氣惜獨于文焉見之故人容或有未
知者然君子取人亦于忠義而已矣
不計其隠與顯也王公履徳行義好
修慕古合傳文以成録捐俸鍥梓名
之曰忠義其所以正天常立人極以
扶持世教者切矣此録在天地間烏
可少哉承公命不可辭作忠義録序
公名偉字資邁别號坦菴云
正徳十年乙亥孟夏既望
賜進士岀身承徳郎禮部儀制司主
　事後學夷陵鄭元拜識
