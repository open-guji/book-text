大過顛也姤遇也柔遇剛也漸女歸待男行也頤養正也既濟定也歸妹女之終也未濟男之窮也夬决也剛決柔也君子道長小人道憂也

蘇軾改作頤養正也大過顛也姤遇也柔遇剛也夬決也剛決柔也君子道長小人道憂漸女歸待男行也歸妹女之終也既濟定也未濟男之窮也云乾坤至需訟兩兩相從明相反之義大過以下非相從之次□者失之也凡八卦今改正而相從之次相反之義煥然若合符節<朱子□改本同蘇氏>
蔡淵改作大過顛也頤養正也既濟定也未濟男之窮也歸妹女之終也漸女歸待男行也姤遇也柔遇剛也夬決也剛決柔也君子道長小人道憂也云自大過以下有亂簡案雜卦例皆反對協韻為序今以其例改正<吳氏澄同　邱富國曰今依蔡易讀之則八卦既得以類從而韻亦叶但不當僭改經文耳　董真卿案蘇氏亦有改正自頤大過而下數卦然不若蔡氏之妥　熊朋來自姤遇也以下後儒多以意改定或違對卦之例或失古韻之音惟蔡氏所改定者為可通故熊氏本同蔡氏>俞琰曰頤養正也大過顛也既濟定也未濟男之窮也歸妹女之終也漸女歸待男行也姤遇也柔遇剛也夬決也剛決柔也君子道長小人道憂也
毛竒齡曰疑改作大過顛也頤養正也漸女歸待男行也歸妹女之終也既濟定也未濟男之窮也姤遇也柔遇剛也夬決也剛決柔也君子道長小人道憂也
晁說之曰鄭云自大過顛也以下卦音不協似錯亂失正弗敢改耳
朱子曰自大過以下卦不反對或疑其錯簡今以韻協之又似非誤未詳何義<胡氏炳文曰本義謂大過以下疑其錯簡今以韻協之又似非誤>
