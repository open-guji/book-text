違從臣之荷橐尚邇天威分刺史之虎符誤承人乏銜恩未報懐禄為慙<中謝>伏念臣衰不待年病存餘息寡徒少偶誰復見憐唯影與形自為依倚頃䝉擢用輙昧周防向非上聖之保全乆已衆人之躪躤致身末路徒抱飲氷之憂許國寸心誰謂食荼之苦慨餘生之婉娩悼本志之差池猶簡聖衷使臨郡寄人之欲善誰不如臣恭惟皇帝陛下加惠庶工憫憐舊物自惟孤露曲荷眷存一昨陛辭謬承天奨謂更兩掖備禁闥之腹心親擇便藩近先臣之松檟豈其幸㑹獲此殊私謹當推廣上仁務綏民瘼雖江湖之已逺自分棄遺顧齒髪之未埋尚存丹赤

分符淝水曽墨突之未黔易地膠西自堯天之從欲訓詞寵被犬馬為榮<中謝>伏念臣昨者歸覲闕庭恭承詔命已趨召節中易便藩方問俗以褰帷復驅車而出境頒漢條之寛大誰暇設施瞻周道之倭遲載從行役請臨劇郡尚意牧民豈謂至仁遽蒙曲聴此盖伏遇皇帝陛下慎㣲接下以禮處人顧禀命之數竒荷慈衷之平施知臣捐軀効力義不有事而辭難憐臣愛日用心辰乎來遲而去速庶幾嵗月冀幸㳙埃矧此全齊近臨東海帯牛佩犢襲奢侈之餘風褒衣大裾有舒緩之遺俗責臣共理何術分憂敢不綏靖羣黎推原徳意凡四方之宣力孰匪事君知一物之軫懷則為體國

視重屋之四阿備合宫之五室本聖人向明而治以繼照臨惟天子負扆而朝具嚴班爵凡兹臣庶悉預榮懐臣聞三代以還明王不作九筵之式後世無傳於赫上帝之聰明紹承景運而興起自我作古有開必先深惟宗祀之䖍大闡緫章之制奔星炳耀巳昭示於乾文流水蔽川復助來於雲棟仰規詔㫖親諭徳音用對越於上靈以祇見於文考備班政視朔之禮彌極孝思伸嚴父配天之誠以崇専饗宜一人之有慶得萬國之歡心恭惟皇帝陛下祇承燕謀發敭先烈圜丘方澤之肇造天地顧懷禮器晟樂之聿新神□昭答載興宏壯震耀聲明臣賀厦自私<闕>奉我将之新什疇克形容續王㑹之周書敢忘述作

殊庭秘宇象紫極之規摹列㦸崇牙衛真㳺於飈歘分頒率土焜燿衆觀恭惟皇帝陛下統一混元總齊化育天人交際屢昭格於帝臨海宇欽承悉函蒙於道䕃推原瑞命之始益廣穹昊之休乃倣赤霄肇新華構出神兵於武庫用赫威靈命乗驛之王人寵貽方面壯彤闈之宏敞偉獸楯之騰拏臣叨預守符獲窺聖作東皇太一追誦楚臣之九歌夀宫神君喜聞漢家之故事

臣某言昨䝉㤙知宻州縁母老多病奏乞宫祠差遣伏奉勅差提舉南京鴻慶宫臣已於今月十五日到鎮江府居住訖忠臣出身而事主固巳忘私上聖恕已以及人曲深從欲許還郡組假逸祠宫仰奉俞音重増感涕<中謝>伏念臣少嬰陟岵之感獨恃倚廬之親適當喜懼之時乆抱晦明之疢觀詩人相戒以養盖欲及時惟曽參不洎之悲敢懷擇禄故求閑散兾竊便安方憂避事之誅豈謂容光之照丘園歸處退依緜上之田廪餼尚豐獲慰寒泉之慕㤙踰始望愧負此身兹盖伏遇皇帝陛下躬體至仁務隆孝治憫臣方寸怵迫恕其請命而呼天知臣疾病相依予其事親之餘日俯從駒犢之念使遂犬馬之愚非臣敢期皆上所賜無功竊食永畢願於桑榆有志慕君尚懷忠於畎畝

臣某言昨具奏状縁臣手足風痺筋力不任陳乞致仕伏䝉聖㤙特賜告命許臣守本職致仕仍轉朝議大夫者殘骸已廢悼蒲桞之先衰視䕃幾何顧桑榆之將暮乞身自便上䟽懇辭敢謂俞音許還印綬<中謝>伏念臣昨者叨踰滿溢災釁荐臻頹然憂患之軀抱此罷癃之疾彈冠彚進方多士之逢時解組懷歸豈臣愚之本志退無室廬風雨之託近有衣食饑寒之憂自非筋力之既愆其誰寵利之不欲繇臣賦分涉世多奇仕則為貧獨愧在陳之病窮斯返本尚猶思越之聲傷㣲悃之未伸忽半塗而中廢涕隨言出心與願違此盖伏遇皇帝陛下覆燾曲成高明委照乃眷甘泉之從歸老菟裘之營仍假近班重憐去國垂矜舊物之服御不忍敝帷之棄捐冀療治之復完䇿駑蹇而終奮雖雀䑕貪生之意猶慕聖明而犬馬戀主之誠永違軒陛

臣某言昨䝉聖㤙特落致仕依前提舉南京鴻慶宫所有巳轉官恩例特免追改臣尋具奏辭免縁疾病妨廢乞許臣依前致仕奉聖㫖不允所乞臣已即時望闕祇受訖乞身本以謝事乃沗祠宫納禄所願辭榮重叨華爵迫承威命不獲愚衷祇荷寵靈愈懷憂愧<中謝>伏念臣頃嬰末疾坐廢歴年巳逼衰殘悲嵗月之既往私自憐憫恐夀命之不長所以畏懼滿盈上還印綬䂓求生理思保桑榆庶幾溝壑之未填茍延晷刻之餘息豈謂既安田畝復簡聖心軫其饑寒之屢空記其名字於垂朽特寛衣食之奉不强筋力之愆永惟鴻造之非常莫知悲涕之横集此盖伏遇皇帝陛下愛均臣子施等父師念嘗親侍於末光不欲棄捐於中道臣愚被賜天下歸仁然臣齒髪既彫備嘗衰境春秋已逝無復恒人深自厭其殘生抑何知於榮進雖併日一食尚饘粥之有餘使賦粟萬鍾顧形軀而誰享仰祈天日之照洞察犬馬之誠知下愚之不移恕先迷而不復巳容得謝方傳安車以遺子孫終兾哀矜願賜骸骨而歸卒伍

臣某昨奉詔㫖除臣給事中臣以衰病昔曽致仕力具辭免續奉詔㫖以臣狂率特落職提舉太平宫觀巳拜告命再䝉降到誥一道除臣依前顯謨閣待制宫觀臣已即時望闕祇受訖者隨鋒車之召節方問前塗罷□闥之除書復還真館叨䝉新命假寵餘生感服恩私惟知涕隕<中謝>伏念臣一從病免甘與世違脱風波争奪之塗伏蓬蓽棲遲之地庶安微分所願固窮竊禄斗升敢辭侏儒之飽忘形田野乆成傖父之名誓將飯糗而終身茍幸蔬食而沒齒不圖過聴驟使造朝外憂難强之筋骸内愧不終之名節懇還制詔哀籲聖慈終縁狂率之姿名在譴訶之域斥歸散地仍禠從班彈貢禹之冠誠非本志奪伯氏之邑其又奚言荷上聖之深仁不崇朝而復職恭惟皇帝陛下賞罰必信清明在躬矜臣去國之有年畀臣西清之舊物惟一與一奪之命無有二三而三仕三已之心敢懷愠喜恭承眷渥知未棄遺悼報國之孤忠顧捐軀之無所年齡已晚庶知蘧瑗之非衰病無功徒受支離之粟

伏覩報生擒睦州方賊并巢穴悉已平蕩者戎兵薄伐大興貔虎之師狂狡就擒卒正鯨鯢之戮捷音誕布海宇交歡<中賀>恭惟皇帝陛下子視羣黎愛均一徳軫念困窮之失職重矜刑辟之傷生然而人狃愛而或驕吏翫安而多忽有如暴冦間出不虞乃眷編氓敢隳王畧出攻城邑擅弄庫兵爰申命於虎臣俾恭行於天討人懷敵愾市不易㕓釋醜類之脅從執渠魁而生致蠢兹陋劣忘厥么麽顧已肆於市朝豈足膏於斧鉞七旬弗格初甚逆於苗民三面雖踈終自投於湯網矧乃復除三嵗之乆蕩宥一方之餘憫此敓攘本起萑蒲之盜寖為猖獗遂成京觀之誅雖曰示威豈其得已告勲廟社喜溢神人臣嬰病海隅馳神觀闕先登賈勇莫從負羽之行飲至勞旋復阻獻俘之列

奉制命以哲宗皇帝正史書成特授臣少師依前太宰進封崇國公具表辭免䝉恩特降中使臣批答不允仍斷來章者載筆終篇迄奏編年之盛揚庭渙命遽膺進位之崇欽承出綍之公弗遂循墻之避超踰益甚震慄彌深臣聞三代之得斯民各極一王之制五典之言常道是為萬世之師故凡經徳出治之君必有繫日謹時之紀洪惟盛典尤篤斯文惇史備言既參以儒紳之博崇論谹議又縂于宰揆之嚴匪惟尊史氏之傳盖欲信帝猷之著臣賦資遲鈍涉道空虚問一得三素非達識襲六為七尤愧通才偶充位於機衡粗服勤於夙夜竊觀聖治克篤寧人雖貽厥孫謀盡迪元豐之烈而昭哉嗣服具存紹聖之規肆恢纉緒之圖必啓因心之念聖有謨訓將垂示於方來志在春秋大發明於錫典載嚴訓飭申命編摩而臣猥以淺聞監于羣議商周所尚雖百世而可知㳺夏之徒顧一辭其敢措訖煩宸筆首賁雲章洎兹汗簡之成獨辱明綸之逮冠亞師之重綬啓崇國之全封洪範之叙九疇詎識彞倫之次内史之詔八柄更叨爵禄之榮仰戴弗勝疾顛云懼此盖伏遇皇帝陛下惟幾惟康以飭庶事有典有則以監百王文武之治憂勤躬秉日新之徳堯舜之道孝悌誠深天顯之懷闡厥宏綱敷時茂賞臣敢不益堅素守少助疇咨質而不俚辨而不華顧豈慚於良史測之益深窮之益逺斯終奉於成謨

臣某言伏覩進奏院報宣撫司奏大兵已於四月撫定燕雲兩路皇帝御文徳殿受文武百僚稱賀者燕雲故地乆隔中原睿聖當天每懷北顧敿干□胄大詰於戎兵取亂侮亡不殺之神武<中賀>恭惟皇帝陛下智謀獨斷威命誕敷眷惟朔野之封近自幽州之壤皇天既付中國奄甸庶邦食土誰非王臣獨淪外域肆興貔虎之衆漸復燕趙之區徳澤川流逺人麕至爰綏懷其種類用申畫於郊圻復舊族之衣冠拯遺黎於塗炭蓋春秋稱王者無外且舉在邦域之中惟聖人以天下為家孰云去父母之國臣庇身祠館抱疾海隅欣聞順動之師慰彼攸徂之衆不圖父老復見漢官之威儀有此雋功其在武丁之孫子

臣某言伏覩進奏院報今月十二日奉上皇太后册寳者尊事母慈本一人之孝愛具嚴典册慰四表之驩心天地與能神人溢喜臣某誠懽誠抃頓首頓首皇太后輔承徽考誕育聖躬推原履武之祥實啓生商之兆從蒼梧之南狩尚逺清塵奉長樂之東朝宜膺殊禮恭惟皇帝陛下至仁出於天性篤行通乎神明惟知順事以解憂不以得位而為樂乃者明堂嚴配深懷霜露之思陟屺遐瞻猶隔晨昏之養故崇位號用極聖情載新焜燿之容彌顯劬勞之徳初務和戎屈伸之略欲以寧親終成用師燮伐之謀斯為養志仰惟信順昭格顯幽凡兹在服之臣舉有移忠之志臣逺違觀闕病伏海瀕欣聞法駕之歸行慶寢門之問
