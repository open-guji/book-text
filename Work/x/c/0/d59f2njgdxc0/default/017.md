## 重刊跋

靜菴趙先生文集。有二板本。一藏于大邱。一藏于綾州竹樹書院。歷百數十年。爲考德徵獻之所。至頃歲。書院撤。而板無所庇。尋不戒于火。大邱之板。又刓缺不完。四方學者。齎咨歎惋。久而不置。乃於今年春。湖南諸章甫。裒然首議。太學嚮應。峙貲竱力。重登于梓。工旣竣。先生後孫承宣命敎。以其事示範朝。屬以一言記後。範朝惟是集序跋爲宋文正公，朴文純公之文。而其於屬辭。猶尙兢畏。退託曰不韙。曰不敏，不揆。況範朝輇材窾識。其敢以姓名。玷簡編之末。以羞當世之士哉。然惟範朝先祖文翼公。實與先生同朝。以大臣保護士類。光輝在國乘。而兩家子孫。亦私相講睦往來。雖以範朝之愚。其嚮慕先生之遺烈。不啻倍蓰餘人。而承宣之屬於範朝者。職以是耳。非謂範朝之知德而嫺於言也。範朝亦奚敢辭。謹書其歲月。俾後之觀於斯文者。尙有以攷其前後焉。抑嘗聞之。聖賢君子之生于世。有德斯有功。蓋有有功而無德者矣。未有有德而無功者也。管夷吾九合一匡。而不免器小之誚。孟子空言。配禹之抑洪水。微此。則義利王霸之界混。而所謂功者。皆徼幸苟且之術也。謹按跋文曰。得君行道。風動一邦。庶幾成其堯舜君民之志。有功於東表。大矣。是固以先生遭際建立而言也。至序文所云。明聖道以闢後人之功。反有加於一時之善治。則幷言先生嘉惠之無窮。而於李文純，李文成兩先生之緖論。相爲表裏。蓋諸賢之言。雖其繁簡之或殊。而其以功歸先生則同。豈非以先生之道德。旣已彰明于後。無竢乎表闡。而惟其德之所以爲功。雖世賴。而日用者或未能著而察焉。故必申申乎其言之歟。使後之學先生者。誠能因是。而皆知德之所以爲功。則出而有爲。必無枉尺詭遇之譏。處而有守。必無摧沮隕穫之患。而其居於廟朝。任斯世之責者。又必如吾先祖之保護士類。惟宗國是憂。則國安得以不理。道安得以不行。而夫豈樹一事標一能以爲功者所可同日而語哉。以範朝之不肖言之。誠有恧。而敢推諸賢餘意。以質于讀先生之書者。是板編敍。一遵舊本。無敢改移。首揭肅廟御製。附載謫廬遺墟碑及書院上樑文。視舊本爲增云。

崇禎紀元後五辛卯孟秋。後學大匡輔國崇祿大夫議政府右議政兼領經筵事，監春秋館事，摠理內務府事，原任奎章閣提學東萊鄭範朝。謹撰。

竹樹書院撤享之後。先集梓板。轉庤私室。蓋緣藏弆之失所也。不幸鬱攸爲虐。蕩於灰燼。士林之齎嗟。尙矣。後承之簪組世襲者。殆亦六七門戶。早宜度材鳩工以新之。迄三年未遑。是豈對人可言者哉。於是乎綾城章甫梁會淵。與同志儕友。刱議重刊。走告京師。國學響應。激勵全省。派助鉅費。遂乃收輯遺文之舊板脫落者與夫年譜之近日編摩者。褎成五冊。懇得右丞相葵堂鄭公之文。以弁卷。鋟工告竣。是役也實幸先集壽其傳。而功存斯文。苟非一省多士慕賢之誠。又非學圃梁先生親炙我先祖。而會淵之祖學圃而繼先志者。惡得以致此。嗚呼。先祖道學德行。雖不敢撰述。而功澤旣洽於八域。尊慕彌遠於百世。一臠片羽。懼或湮沒。更謀剞劂。以壽其傳。永世無窮。湖之人士。尤當嚮慕尊奉。永有辭於千秋矣。詩曰。高山仰止。景行行止。聊以是誦之。

崇禎紀元後五壬辰孟春。後孫通政大夫承政院左副承旨兼經筵參贊官，春秋館修撰官命敎。謹識。
