## 用户 09-26 原话要点

- 分**具体版本**与**未知版本**：「未知版本的放 work」。
- 「绝大部分一个 work 下边只有一个版本，但有的时候可能会有多个版本，我们可能还是要区分一下。」
- 识典暂不抓（book-text 是公开仓，存进去等于转载），**先只抓维基文库**（CC BY-SA 4.0）。

## 落点

```
Book/<c1>/<c2>/<c3>/<book_id>/full_text/          版本已知：挂在那个 Book 上（现状，不变；网站「全文」tab 已读它）
├── index.json
└── NNN.md

Work/<c1>/<c2>/<c3>/<work_id>/full_text/<key>/    版本未知：挂在 Work 下，一份文本一个子目录
├── index.json
└── NNN.md
```

- `<key>` = `<来源>-<两位序号>`，如 `wikisource-01`、`wikisource-02`。**只用 ASCII**；同一 Work 下同一来源有几份就编几号，序号按入库先后，**一经发出不改号**（外部可能已引用）。
  即使一个 Work 下只有一份，也照样建 `wikisource-01/` 子目录——**不为「多数只有一份」省一层**，否则第二份来的时候要搬家。
- `index.json` 与 Book 全文**同一 schema**（见现有 `Book/*/96kzkmzcow/full_text/index.json`），外加：
  - `work_id`（Work 下的必填；Book 下的写 `book_id`，照旧）
  - `source.page_title`：来源页面名（维基即条目名，如 `論語`、`周易 (四部叢刊本)`）
  - `source.revid`：抓取时的修订号（维基 `revid`），用于日后判断要不要重抓
  - `edition_note`：**来源自述的底本**（如维基页面头注「據四部叢刊本」）。能对上 book-index 里既有 Book 的就不该落 Work（见下），对不上的记在这里，留给日后升格
  - `text_quality.grade`：维基抓取一律先标 `source`（抓取原样，未校），与整理本同一套分级
- `Work/<wid>/sources/<来源>/` **另是一回事**：那是**整理本的底料**（ctext、source_text），不是给读者看的全文，**不要混用**。

## 判「版本已知」的规矩（抓取道照此分流）

落 `Book/<bid>/full_text/` **须同时满足**：

1. 来源页面**明说**底本（页头注、`{{Header}}` 的 `notes`／`edition` 之类），不是抓取者推测的；
2. book-index 里该 Work 下**已有**对得上这个版本的 Book 条目（版本名、刊刻年、丛书名至少一项明确吻合）；
3. 该 Book 还没有 `full_text/`。

任一不满足 → 落 `Work/<wid>/full_text/<key>/`，底本自述写 `edition_note`。
**抓取道不建 Book 条目**（那是目录的写域）；「本该建个 Book」的，列进 `done` 单，由文本总管转 `cross` 单给目录总管。

## 日后升格

Work 下某份文本认出了版本、目录那边也建好了 Book → `git mv Work/<wid>/full_text/<key>/ Book/<bid>/full_text/`，`index.json` 补 `book_id`、删 `work_id`，**原 key 号作废不复用**。
