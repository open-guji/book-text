## 结论
**json 标题没错，错的是「同号配对」：全书 json 编号 = md 编号 + 4。**

- `NNN.json` 的 title／page_title 与其正文一致：001–004 = 卷首1–4，005 = 卷001，……，204 = 卷200。
- `NNN.md` 的标题与正文一致（#95 已修）：001 = 卷001，……，200 = 卷200。
- 实测：md 005–200（196 章）逐章取书名前缀去 json 里找，**196/196 在 json N+4 命中率 ≥ 同号命中率**；md 001 开头「經稟聖裁…」（經部總敍）在 json 005（卷001）。
- 所以 md N ↔ json N+4（N=1..200）；json 001–004（卷首1–4）没有对应 md；205 为附錄（md、json 同号，不偏）。
- 1a（201–204 只有 json）因此得到解释：它们就是卷197–200 的 json，对应 md 197–200，**不是多余文件，不能删**。

## 后果
index.json 的 `has_json: true` 与 spec 07 §4.2「同名 NNN.json」把 `NNN.md` 与 `NNN.json` 配成一对；本书配错 4 位，下游（阅读器按同名取 json 的分段／实体）会把卷001 的 md 配到卷首1 的 json。
