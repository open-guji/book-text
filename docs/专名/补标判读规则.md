## 一、先看 hi 档（人名 ≥3 字、书名带引导词）
1. **N8 hi（人名）**：上下文是人名用法（「某朝某某撰」「某某字X」「某某曰」「某某經義考」）→ `补标`，`target_id`＝`match_id`（`match_id` 是 `ambig:…` 的改填 `存疑`）。
2. **hi 里的误报**（书名里的人名，如「朱彝尊經義考」中的「朱彝尊」是人，不是误报；而「某某集解」整体是书名时人名不单标）：判为 `不标`，理由码 `已被长实体覆盖`（该处属某书名）。
3. **N9 hi（书名）**：前面有「撰／著／云／載／見／據」等引导词，且这串字确是一部书 → `补标`（type=work，target＝`match_id`）；是篇名／经名／泛称（繫辭傳、六十四卦、永樂大典作类名等）→ `不标`，理由码 `篇名`／`普通词`。

## 二、lo 档（两字名、紧邻数字、停用词近邻）
| 情形 | 例 | 处置 |
|---|---|---|
| 两字，上下文有「X撰／X字／X曰／X說／X注／X之學」且是历史人物 | 王弼、江總、劉牧、胡瑗、俞琰 | `补标`，`ok` |
| 学者简称或尊称，指同一人 | 朱子、邵子、孔子 | `补标`，`target_id` 填库里对应人物（朱子→朱熹）；`match_id` 对不上则 `存疑` |
| 名简称（N6）：同段前面出现过全名 | 良輔（熊良輔）、應麟（王應麟） | `补标`，`target_id`＝全名人物 id，备注「N6」 |
| 以「氏」结尾 | 王氏、鄭氏 | `不标`，`氏`（脚本已大多跳过） |
| 地名、年号、官名、普通词误撞人名 | 明初、金華、言人、簡明、高明、史本、王孫、王所 | `不标`，`普通词` |
| 书名里的字 | 易象、周易（不是人）| `不标`，`已被长实体覆盖`或`普通词` |
| 同名多人，上下文不能定 | `match_id` 为 `ambig:…` | `存疑`（交 P3 同一套消歧规则，不在这里猜） |
| 数字邻（「十七」「四十」）| 四十、成書 | `不标`，`数字`／`普通词` |
| 朝代前缀粘连（「明劉日升」）| | 本候选取名字部分，朝代 N7 另处理，名字 `补标` |
